# Final editing check

Use this as a brief review of the actual edit, not a mandatory report or scoring system.

- **Meaning:** facts, attribution, numbers, units, negation, conditions, and uncertainty remain accurate. No invented details or stronger claims appeared.
- **Protection:** quoted material and technical tokens remain intact within the authorized scope.
- **Voice:** the writer's characteristic language and cadence survive unless a transformation was requested.
- **Clarity:** each change fixes an observable problem for this audience. Clear passages were not rewritten merely for consistency.
- **Context:** pattern matches were judged by function. No word, punctuation mark, grammatical voice, or list length was treated as a universal defect.
- **Delivery:** return the requested artifact or findings. Detect mode leaves the source unchanged and makes no authorship claim.

Repair a concrete regression if one is found. Stop when the requested edit is sound; do not keep revising to maximize a score.
