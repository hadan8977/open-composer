# Visual concepts and assets

Use a visual artifact to resolve a real uncertainty in composition, identity, imagery, or interaction. Follow [new-work](new-work.md) and the selected direction; do not reopen settled choices.

## Choose the medium

- Use a reference board to explain sources and transferable principles.
- Use a wireframe or native UI prototype to compare hierarchy, topology, and task flow.
- Use a high-fidelity comp when typography, imagery, material, or visual ambition needs a concrete reference.
- Use the host-provided `imagegen` skill, when available, for requested raster assets or generated concepts. Resolve it through the host's skill catalog. Prefer editable native assets for existing vectors, icons, geometry, and real UI.

Image generation is not a prerequisite for good design. A static comp does not demonstrate a working interaction.

## Compare fairly

When a direction is open, make a few materially different proposals at the intended viewport and comparable fidelity. Use consistent real or clearly illustrative content, label each proposal, and explain its thesis and tradeoff.

Actually inspect the outputs before presenting them. Ensure the composition supports the intended task and can adapt to the required screens. Generated text and visual polish do not establish product capabilities, real customers, or measured performance.

Choose or recommend a direction within the user's authorization. A user who asked to select receives a reviewable choice. A user who delegated selection receives the selected concept and reasoning without another mandatory approval round.

## Translate the selected design

Identify its structural relationships, type hierarchy, image regions, semantic controls, and responsive behavior. Preserve the concept's distinctive choices while adapting details needed for real content, accessibility, and interaction.

Do not flatten an ambitious selected direction into a generic layout because the first implementation is easier. Explain a material feasibility conflict and resolve it before silently substituting a different direction.

Real text, controls, and focus indicators remain semantic. Use real imagery or produced assets where the design depends on them; use native geometry where it is the intended medium. Keep sources and generated proposals distinguishable, preserve applicable attribution, and save project-consumed assets in the project.

The bundled comp tooling is optional. When explicitly selected, follow its actual phase and input requirements. It does not impose additional approval, file generation, or tool installation on other workflows.
