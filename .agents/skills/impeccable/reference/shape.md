# Shape

Discover what should be made and how it should work, then return a useful design brief. Planning does not authorize implementation.

Follow [new-work](new-work.md) through the stages needed to resolve the brief. Reuse existing discovery and design direction. Do not ask the user to restate settled facts or choose CSS values.

Ask only about decisions that materially change the result: intended user and task, success, real content, constraints, scope, or a genuinely open direction. If the user delegates judgment, make a recommendation or choose with stated assumptions.

For new or replacement directions, study actual visual references and compare meaningfully different concepts. For an addition within a coherent existing surface, resolve only its hierarchy, behavior, and fit.

Return the smallest brief the builder needs:

- User, situation, primary task, and success.
- Selected direction, reference principles, and the reason for the choice.
- Information hierarchy, composition, key interactions, and responsive intent.
- Real content ranges, meaningful states, constraints, and preserved behavior.
- Material assumptions or decisions still requiring the user's input.

A settled local task may need only a few bullets. Multi-screen work may need a structured brief and viewable concept samples.

If a choice remains, present the alternatives with a recommendation. Otherwise deliver the brief and stop. Do not add a mandatory confirmation round or create project records unless the request includes that work.
