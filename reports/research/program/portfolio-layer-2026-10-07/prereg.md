## 配置规则（共 7 个，加 1 次 EWMA 稳健性，试验数 = 8）

- **A0**：现在的资金分配（美元计价），作基线。F1 基数以 `plans/2026-10-06.json` 的 equity_basis 1,000,000 为准；路线图提到可能改成约 300,000，作敏感性。
- **A1**：风险预算（ERC 的带预算版本）。预算 b_i：观察仓 b=0.10，其余均分 0.90/(N−1)。
- **A2**：最大夏普均值–方差。μ_i = 先验夏普 × σ_i（σ_i 来自收缩协方差）；先验：P1 = 0.59（校准里 DSR≥0.70 通过者的真实夏普期望 0.588），P0 = 0.45（P1 与观察仓之间的中点，假设），观察仓 = 0.30（校准网格第一个非零点，假设）。权重非负、和为 1，每个子策略风险贡献占比 ≤ 上限，观察仓 ≤ 10%。求解失败回退 A1。
- **A3**：A2 加市场状态，**条件**：`data/features/regime_daily/` 里只有 `spy_ret_20` 和 `spy_gap_200sma` 可以用（`vix_close` 混用 CBOE 文件和 `spy_vol_21` 回填，来源不一致，排除；`cs_dispersion_21`、`breadth_50d` 的总体口径没有时点审计，排除）。启用前必须通过代码测试：截断未来数据重算，当日值不变。通过则：状态 = `spy_gap_200sma` < 0（t 日收盘后判定，t+1 日起用）；μ_i(状态) = 先验 × clip(SR_i|状态 / SR_i|全部, 0, 2)，其中条件夏普**只用压力期**估；近期窗口不参与估计。不通过则写"未做"和原因。
- **A4**：A2 加子策略回撤止损：子策略自身累计净值从高点回撤 > k × 年化波动（过去 252 日）时，该子策略权重减半、空出部分放现金（收益 0），回撤收窄到 0.5·k 倍年化波动以内后恢复。k ∈ {2, 3, 4}（3 个规则）。多经理平台的 5% 止损是二手说法，只用来确定量级，不抄。

## 风险占比上限

- 子策略数 N < 5 时 20% 不可行（N·20% < 100%）。替代：上限 = min(1, 1.5/N)，即 1/N 加 50% 余量；N=6 时 25%，N=4 时 37.5%。理由：保证可行（N·cap = 1.5 ≥ 1）又限制任一子策略主导（S3 单独占近期风险 43%，见账户评审）。
- 观察仓风险占比 ≤ 10%；资金占比（占账户资金）≤ 10%，由 check 命令检查。

## 评价

- 滚动：过去 252 日估计，每月第一个交易日调整，到下个调整日前权重随各子策略收益漂移。
- 指标：账户级净夏普、最大回撤、配置换手（每次调整 Σ|w_目标−w_漂移|/2 的年化）。
- 同波动比较：各规则组合收益统一缩放到近期窗口年化波动 10% 再比较回撤（夏普与缩放无关）。
- 配对自助法（平稳块，平均块长 21 日，2000 次，种子 20261008）给"规则 − A0"、"规则 − A1"的夏普差区间。

## 回撤预算和保证金

- 对选出的规则，用近期窗口的滚动配置日收益：去均值后加上"收缩后的日均值"（P1 先验口径）做平稳块自助法（块长 21，2000 条，每条 504 个交易日，种子 20261008），求放大倍数 L，使 2 年最大回撤的 95% 分位 ≤ 30%（二分法，L∈[0.1, 6]）。借入部分 L−1 按 7% 年化计融资成本（待核对 Alpaca 当前保证金利率；敏感性 5–9%）。
- 保证金：隔夜总敞口（Σ w_i · g_i · L，g_i 为每 1 美元子策略资金的总敞口倍数）quant1 ≤ 2.0、主账户 ≤ 2.0（Reg T）；quant2 日内 ≤ 4.0。g_i：F1 取账本 `gross` 列的 p95；ETF 子策略取规格的最大杠杆（杠杆 ETF 按其倍数计，如 TQQQ 3 倍）；缺则按保守值并写"待"。取 L = min(L_回撤, L_保证金)。
- 输出放大后预期年化收益；敏感性：夏普 = 原始样本值、收缩值、收缩值×0.5、收缩值−1 个标准误（标准误 ≈ 1/√年数）时 L 和预期收益各是多少。
- 因为各账户是独立资金池（不能互相划转），账户层应用 = 对每个账户只用它自己的子策略跑同一规则，再按上面规则求 L；程序层（6 个）只用来回答"规则是否带来夏普增量"。

## 验证和"还差几个"

- 代码验证：8 个子策略、两两相关 0.1、真实夏普 1.0、等波动等权 → 账户夏普 = 8/√(8+8·7·0.1) = 2.17（闭式）；用模拟（T 足够大）核对在 ±0.05 内。
