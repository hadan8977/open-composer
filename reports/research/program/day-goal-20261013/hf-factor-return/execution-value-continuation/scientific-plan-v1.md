令z_t为已恢复的log预测、L=1为固定延迟，未来第s个可交易区间的假设预期简单收益为

    mu[t,s] = expm1(rho ** (L + s - 1) * z_t).

这是一组**事前情景假设**，不是另外h条训练预测，也不读取未来时点的实际预测或实现回报。rho快=1/2，慢=2^(-1/4)：15分钟和1小时半衰期。以固定设置检验这两种寿命，而不从旧样本最优回归估计rho。相邻预测自相关本身不证明实现收益寿命。

共同线性成本目标（以权益收益单位）：

    V_s(v) = max_w { mu[t,s] * (w-b)
                     - (gamma/2) * sigma[t,s]^2 * (w-b)^2
                     - c * abs(w-v) + V_(s+1)(w) },
    V_(H+1)(w) = -c * abs(w-b).

c=20bp单侧；实际40bp压力账使用c=40bp而不降费用。gamma=10固定，不优化。终端项为回到anchor的**规划费用负债**，既不创造终端现金也不强行在样本末日清仓；既有仓位的第一步也有相同负债。规划的期望风险/收益不是资金，账本只使用真现金/参考成交。sigma为此前63个已完成会话raw SPY对应15分钟收益的均方根（包括跳变、不减到零），严格shift；不足30个可用历史会话时用预注册0.004简单收益标准差。该固定矩是成本政策的风险度量，无模型或优化训练。无用未来波动调仓；迟到/缺失价格不给sigma伪造条目。这里不是连续权重/无限期限数学最优；检验小离散策略的经济价值。
