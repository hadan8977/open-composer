<span class="property"><span class="k"><span class="pre">class</span></span><span class="w"> </span></span><span class="sig-prename descclassname"><span class="pre">skfolio.model_selection.</span></span><span class="sig-name descname"><span class="pre">CombinatorialPurgedCV</span></span><span class="sig-paren">(</span><em class="sig-param"><span class="n"><span class="pre">n_folds</span></span><span class="o"><span class="pre">=</span></span><span class="default_value"><span class="pre">10</span></span></em>, <em class="sig-param"><span class="n"><span class="pre">n_test_folds</span></span><span class="o"><span class="pre">=</span></span><span class="default_value"><span class="pre">8</span></span></em>, <em class="sig-param"><span class="n"><span class="pre">purged_size</span></span><span class="o"><span class="pre">=</span></span><span class="default_value"><span class="pre">0</span></span></em>, <em class="sig-param"><span class="n"><span class="pre">embargo_size</span></span><span class="o"><span class="pre">=</span></span><span class="default_value"><span class="pre">0</span></span></em><span class="sig-paren">)</span><a class="reference internal" href="../_modules/skfolio/model_selection/_combinatorial.html#CombinatorialPurgedCV"><span class="viewcode-link"><span class="pre">[source]</span></span></a><a class="headerlink" href="#skfolio.model_selection.CombinatorialPurgedCV" title="Link to this definition">#</a></dt>
<dd><p>Combinatorial Purged Cross-Validation.</p>
<p>Provides train/test indices to split time series data samples based on
Combinatorial Purged Cross-Validation <a class="reference internal" href="#re93330c75414-1" id="id1">[1]</a>.</p>
<p>Compared to <code class="docutils literal notranslate"><span class="pre">KFold</span></code>, which splits the data into <code class="docutils literal notranslate"><span class="pre">k</span></code> folds with <code class="docutils literal notranslate"><span class="pre">1</span></code> fold for the test
set and <code class="docutils literal notranslate"><span class="pre">k</span> <span class="pre">-</span> <span class="pre">1</span></code> folds for the training set, <code class="docutils literal notranslate"><span class="pre">CombinatorialPurgedCV</span></code> uses <code class="docutils literal notranslate"><span class="pre">k</span> <span class="pre">-</span> <span class="pre">p</span></code>
folds for the training set with <code class="docutils literal notranslate"><span class="pre">p</span> <span class="pre">&gt;</span> <span class="pre">1</span></code> being the number of test folds.</p>
<p><code class="docutils literal notranslate"><span class="pre">KFold</span></code> can recombine one single testing path while <code class="docutils literal notranslate"><span class="pre">CombinatorialPurgedCV</span></code> can
recombine multiple testing paths from the combinations of the train/test sets.</p>
<p>To avoid data leakage, purging and embargoing can be performed.</p>
<p>Purging consists of removing from the training set all observations whose labels
overlapped in time with those labels included in the testing set.</p>
<p>Embargoing consists of removing from the training set all observations that
immediately follow an observation in the testing set, since financial features
often incorporate series that exhibit serial correlation (like ARMA processes).</p>
