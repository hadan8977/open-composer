  <section id="model-selection">
<span id="id1"></span><h1>Model Selection<a class="headerlink" href="#model-selection" title="Link to this heading">#</a></h1>
<p>The Model Selection module extends <code class="docutils literal notranslate"><span class="pre">sklearn.model_selection</span></code> by adding additional
methods tailored for portfolio selection.</p>
<section id="online-learning">
<h2>Online Learning<a class="headerlink" href="#online-learning" title="Link to this heading">#</a></h2>
<p>In addition to fold-based cross-validation utilities,
<code class="docutils literal notranslate"><span class="pre">skfolio.model_selection</span></code> provides stateful online utilities for estimators
that support <code class="docutils literal notranslate"><span class="pre">partial_fit</span></code>. These utilities update a single estimator through
time instead of fitting an independent clone on each split, which is
particularly useful for exponentially weighted moments and portfolio optimizers
built on top of them.</p>
<p>See <a class="reference internal" href="online_learning.html#online-learning"><span class="std std-ref">Online Learning</span></a> for the full workflow and the differences between
online evaluation and standard cross-validation.</p>
</section>
<section id="cross-validation-prediction">
<span id="cross-validation"></span><h2>Cross-Validation Prediction<a class="headerlink" href="#cross-validation-prediction" title="Link to this heading">#</a></h2>
<p>Every <code class="docutils literal notranslate"><span class="pre">skfolio</span></code> estimator is compatible with <code class="docutils literal notranslate"><span class="pre">sklearn.model_selection.cross_val_predict</span></code>.
We also implement our own <a class="reference internal" href="../generated/skfolio.model_selection.cross_val_predict.html#skfolio.model_selection.cross_val_predict" title="skfolio.model_selection.cross_val_predict"><code class="xref py py-func docutils literal notranslate"><span class="pre">cross_val_predict</span></code></a> for enhanced integration
with <code class="docutils literal notranslate"><span class="pre">Portfolio</span></code> and <code class="docutils literal notranslate"><span class="pre">Population</span></code> objects, as well as compatibility with
<a class="reference internal" href="../generated/skfolio.model_selection.CombinatorialPurgedCV.html#skfolio.model_selection.CombinatorialPurgedCV" title="skfolio.model_selection.CombinatorialPurgedCV"><code class="xref py py-class docutils literal notranslate"><span class="pre">CombinatorialPurgedCV</span></code></a> and <a class="reference internal" href="../generated/skfolio.model_selection.MultipleRandomizedCV.html#skfolio.model_selection.MultipleRandomizedCV" title="skfolio.model_selection.MultipleRandomizedCV"><code class="xref py py-class docutils literal notranslate"><span class="pre">MultipleRandomizedCV</span></code></a>.</p>
<div class="admonition danger" id="data-leakage">
<p class="admonition-title">Danger</p>
<p>When using <code class="docutils literal notranslate"><span class="pre">scikit-learn</span></code> selection tools like <code class="docutils literal notranslate"><span class="pre">KFold</span></code> or <code class="docutils literal notranslate"><span class="pre">train_test_split</span></code>, ensure
that the parameter <code class="docutils literal notranslate"><span class="pre">shuffle</span></code> is set to <code class="docutils literal notranslate"><span class="pre">False</span></code> to avoid data leakage. Financial
features often incorporate series that exhibit serial correlation (like ARMA
processes) and shuffling the data will lead to leakage from the test set to the
training set.</p>
</div>
<p>In <code class="docutils literal notranslate"><span class="pre">cross_val_predict</span></code>, the data is split according to the <code class="docutils literal notranslate"><span class="pre">cv</span></code> parameter.
The portfolio optimization estimator is fitted on the training set and portfolios are
predicted on the corresponding test set.</p>
<p>For <code class="docutils literal notranslate"><span class="pre">scikit-learn</span></code> cross-validation methods such as <code class="docutils literal notranslate"><span class="pre">KFold</span></code> and <code class="docutils literal notranslate"><span class="pre">skfolio</span></code>’s
<code class="docutils literal notranslate"><span class="pre">WalkForward</span></code>, the output is a <a class="reference internal" href="../generated/skfolio.portfolio.MultiPeriodPortfolio.html#skfolio.portfolio.MultiPeriodPortfolio" title="skfolio.portfolio.MultiPeriodPortfolio"><code class="xref py py-class docutils literal notranslate"><span class="pre">MultiPeriodPortfolio</span></code></a>, where
each <a class="reference internal" href="../generated/skfolio.portfolio.Portfolio.html#skfolio.portfolio.Portfolio" title="skfolio.portfolio.Portfolio"><code class="xref py py-class docutils literal notranslate"><span class="pre">Portfolio</span></code></a> corresponds to the prediction on a single
train/test split (resulting in K portfolios for <code class="docutils literal notranslate"><span class="pre">KFold</span></code>).</p>
<p>For combinatorial cross-validation methods such as <a class="reference internal" href="../generated/skfolio.model_selection.CombinatorialPurgedCV.html#skfolio.model_selection.CombinatorialPurgedCV" title="skfolio.model_selection.CombinatorialPurgedCV"><code class="xref py py-class docutils literal notranslate"><span class="pre">CombinatorialPurgedCV</span></code></a> and
Monte Carlo-style methods such as <a class="reference internal" href="../generated/skfolio.model_selection.MultipleRandomizedCV.html#skfolio.model_selection.MultipleRandomizedCV" title="skfolio.model_selection.MultipleRandomizedCV"><code class="xref py py-class docutils literal notranslate"><span class="pre">MultipleRandomizedCV</span></code></a>, the output is a
<a class="reference internal" href="../generated/skfolio.population.Population.html#skfolio.population.Population" title="skfolio.population.Population"><code class="xref py py-class docutils literal notranslate"><span class="pre">Population</span></code></a> containing multiple
<a class="reference internal" href="../generated/skfolio.portfolio.MultiPeriodPortfolio.html#skfolio.portfolio.MultiPeriodPortfolio" title="skfolio.portfolio.MultiPeriodPortfolio"><code class="xref py py-class docutils literal notranslate"><span class="pre">MultiPeriodPortfolio</span></code></a>. This is because each test produces a
collection of multiple paths rather than a single path.</p>
<p>Portfolio parameters can be set in the portfolio optimizer’s <code class="docutils literal notranslate"><span class="pre">portfolio_params</span></code> or
passed to <code class="docutils literal notranslate"><span class="pre">cross_val_predict</span></code>. The parameters shared by
<a class="reference internal" href="../generated/skfolio.portfolio.Portfolio.html#skfolio.portfolio.Portfolio" title="skfolio.portfolio.Portfolio"><code class="xref py py-class docutils literal notranslate"><span class="pre">Portfolio</span></code></a> and
<a class="reference internal" href="../generated/skfolio.portfolio.MultiPeriodPortfolio.html#skfolio.portfolio.MultiPeriodPortfolio" title="skfolio.portfolio.MultiPeriodPortfolio"><code class="xref py py-class docutils literal notranslate"><span class="pre">MultiPeriodPortfolio</span></code></a> (<code class="docutils literal notranslate"><span class="pre">compounded</span></code>, <code class="docutils literal notranslate"><span class="pre">risk_free_rate</span></code>,
<code class="docutils literal notranslate"><span class="pre">annualization_factor</span></code>, <code class="docutils literal notranslate"><span class="pre">fitness_measures</span></code> and the risk measure parameters) are applied
to the resulting <code class="docutils literal notranslate"><span class="pre">MultiPeriodPortfolio</span></code> and to each <code class="docutils literal notranslate"><span class="pre">Portfolio</span></code> it contains. A value
passed to <code class="docutils literal notranslate"><span class="pre">cross_val_predict</span></code> takes precedence over the optimizer’s <code class="docutils literal notranslate"><span class="pre">portfolio_params</span></code>.
When omitted, it is inherited from the optimizer’s <code class="docutils literal notranslate"><span class="pre">portfolio_params</span></code>, and
<code class="docutils literal notranslate"><span class="pre">risk_free_rate</span></code> falls back to the optimizer’s <code class="docutils literal notranslate"><span class="pre">risk_free_rate</span></code> parameter when it has
one. For example, <code class="docutils literal notranslate"><span class="pre">MeanRisk(portfolio_params={&quot;compounded&quot;:</span> <span class="pre">True})</span></code> produces a
compounded <code class="docutils literal notranslate"><span class="pre">MultiPeriodPortfolio</span></code> from <code class="docutils literal notranslate"><span class="pre">cross_val_predict</span></code> without repeating the
setting. These parameters only affect how the portfolios are measured: a
<code class="docutils literal notranslate"><span class="pre">risk_free_rate</span></code> passed to <code class="docutils literal notranslate"><span class="pre">cross_val_predict</span></code> does not change the optimizer’s own
<code class="docutils literal notranslate"><span class="pre">risk_free_rate</span></code>.</p>
<p><code class="docutils literal notranslate"><span class="pre">weight_drift</span></code> applies to each <code class="docutils literal notranslate"><span class="pre">Portfolio</span></code> of the path. With <code class="docutils literal notranslate"><span class="pre">weight_drift=True</span></code>, the
weights held within each test window drift with the asset returns, and the path runs
sequentially. A value passed to <code class="docutils literal notranslate"><span class="pre">cross_val_predict</span></code> overrides the optimizer’s
<code class="docutils literal notranslate"><span class="pre">portfolio_params</span></code>. Optimizer parameters such as <code class="docutils literal notranslate"><span class="pre">transaction_costs</span></code>,
<code class="docutils literal notranslate"><span class="pre">management_fees</span></code> and <code class="docutils literal notranslate"><span class="pre">previous_weights</span></code> are not accepted in the function’s
<code class="docutils literal notranslate"><span class="pre">portfolio_params</span></code>: set them on the optimizer, which forwards them to the predicted
<code class="docutils literal notranslate"><span class="pre">Portfolio</span></code> objects. <code class="docutils literal notranslate"><span class="pre">name</span></code>, <code class="docutils literal notranslate"><span class="pre">tag</span></code>, <code class="docutils literal notranslate"><span class="pre">sample_weight</span></code> and <code class="docutils literal notranslate"><span class="pre">check_observations_order</span></code>
apply to the resulting <code class="docutils literal notranslate"><span class="pre">MultiPeriodPortfolio</span></code> only.</p>
<p>By default, the resulting portfolio inherits its children’s sample weights.
An explicit <code class="docutils literal notranslate"><span class="pre">sample_weight</span></code> overrides them (see <a class="reference internal" href="portfolio.html#portfolio"><span class="std std-ref">Portfolio</span></a>).</p>
<p>For example, to evaluate a drifted, compounded path with transaction costs:</p>
<div class="highlight-python notranslate"><div class="highlight"><pre><span></span><span class="n">pred</span> <span class="o">=</span> <span class="n">cross_val_predict</span><span class="p">(</span>
    <span class="n">MeanRisk</span><span class="p">(</span><span class="n">transaction_costs</span><span class="o">=</span><span class="mf">0.001</span> <span class="o">/</span> <span class="mi">5</span><span class="p">),</span>
    <span class="n">X</span><span class="p">,</span>
    <span class="n">cv</span><span class="o">=</span><span class="n">WalkForward</span><span class="p">(</span><span class="n">test_size</span><span class="o">=</span><span class="mi">5</span><span class="p">,</span> <span class="n">train_size</span><span class="o">=</span><span class="mi">252</span><span class="p">),</span>
    <span class="n">portfolio_params</span><span class="o">=</span><span class="p">{</span><span class="s2">"weight_drift"</span><span class="p">:</span> <span class="kc">True</span><span class="p">,</span> <span class="s2">"compounded"</span><span class="p">:</span> <span class="kc">True</span><span class="p">},</span>
<span class="p">)</span>
</pre></div>
</div>
<p>With a sequential splitter, the <code class="docutils literal notranslate"><span class="pre">ending_weights</span></code> of each portfolio are passed as
<code class="docutils literal notranslate"><span class="pre">previous_weights</span></code> to the next fit. They equal the target weights when
<code class="docutils literal notranslate"><span class="pre">weight_drift=False</span></code> and the weights after the last observation when
<code class="docutils literal notranslate"><span class="pre">weight_drift=True</span></code>, so transaction costs and <code class="docutils literal notranslate"><span class="pre">max_turnover</span></code> are then measured from the
holdings a fund would trade from. A failed period keeps the last successful ending
weights. The sequential path requires one portfolio per fold and raises for estimators
that return a <a class="reference internal" href="../generated/skfolio.population.Population.html#skfolio.population.Population" title="skfolio.population.Population"><code class="xref py py-class docutils literal notranslate"><span class="pre">Population</span></code></a>. With non-sequential splitters
such as <code class="docutils literal notranslate"><span class="pre">KFold</span></code>, drift is evaluated inside each test fold and is not propagated. See
<a class="reference internal" href="backtesting_and_evaluation.html#backtesting-and-evaluation"><span class="std std-ref">Backtesting and Evaluation</span></a> for the choice between <code class="docutils literal notranslate"><span class="pre">weight_drift=False</span></code> and
<code class="docutils literal notranslate"><span class="pre">weight_drift=True</span></code>.</p>
<p><strong>Example:</strong></p>

<section id="walk-forward-cross-validation">
<h2>Walk-Forward Cross-Validation<a class="headerlink" href="#walk-forward-cross-validation" title="Link to this heading">#</a></h2>
<p>The <a class="reference internal" href="../generated/skfolio.model_selection.WalkForward.html#skfolio.model_selection.WalkForward" title="skfolio.model_selection.WalkForward"><code class="xref py py-class docutils literal notranslate"><span class="pre">WalkForward</span></code></a> splitter divides time series data using a walk‑forward approach.
Unlike <code class="docutils literal notranslate"><span class="pre">sklearn.model_selection.TimeSeriesSplit</span></code>, you specify the number of training
and test samples rather than the number of splits, making it more suitable for portfolio
cross‑validation.</p>
<p>If your data is a DataFrame indexed by a <code class="xref py py-class docutils literal notranslate"><span class="pre">pandas.DatetimeIndex</span></code>, you can split it
using specific datetime frequencies and offsets.</p>
</section>
<section id="combinatorial-purged-cross-validation">
<h2>Combinatorial Purged Cross-Validation<a class="headerlink" href="#combinatorial-purged-cross-validation" title="Link to this heading">#</a></h2>
<p>Compared to <code class="docutils literal notranslate"><span class="pre">KFold</span></code>, which splits the data into k folds and generates one single testing
path, the <a class="reference internal" href="../generated/skfolio.model_selection.CombinatorialPurgedCV.html#skfolio.model_selection.CombinatorialPurgedCV" title="skfolio.model_selection.CombinatorialPurgedCV"><code class="xref py py-class docutils literal notranslate"><span class="pre">CombinatorialPurgedCV</span></code></a> uses the combination of multiple
train/test sets to generate multiple testing paths.</p>
<p>To avoid data leakage, purging and embargoing can be performed.</p>
<p>Purging consists of removing from the training set all observations
whose labels overlapped in time with those labels included in the testing set.
Embargoing consists of removing from the training set observations that immediately
follow an observation in the testing set, since financial features often incorporate
series that exhibit serial correlation (like ARMA processes).</p>
<p>When used with <a class="reference internal" href="../generated/skfolio.model_selection.cross_val_predict.html#skfolio.model_selection.cross_val_predict" title="skfolio.model_selection.cross_val_predict"><code class="xref py py-func docutils literal notranslate"><span class="pre">cross_val_predict</span></code></a>, the object returned is a
<a class="reference internal" href="../generated/skfolio.population.Population.html#skfolio.population.Population" title="skfolio.population.Population"><code class="xref py py-class docutils literal notranslate"><span class="pre">Population</span></code></a> of
<a class="reference internal" href="../generated/skfolio.portfolio.MultiPeriodPortfolio.html#skfolio.portfolio.MultiPeriodPortfolio" title="skfolio.portfolio.MultiPeriodPortfolio"><code class="xref py py-class docutils literal notranslate"><span class="pre">MultiPeriodPortfolio</span></code></a> representing each prediction path.</p>
<p><strong>Example:</strong></p>
<div class="highlight-python notranslate"><div class="highlight"><pre><span></span><span class="kn">from</span><span class="w"> </span><span class="nn">skfolio</span><span class="w"> </span><span class="kn">import</span> <span class="n">RatioMeasure</span>
<span class="kn">from</span><span class="w"> </span><span class="nn">skfolio.datasets</span><span class="w"> </span><span class="kn">import</span> <span class="n">load_sp500_dataset</span>
<span class="kn">from</span><span class="w"> </span><span class="nn">skfolio.model_selection</span><span class="w"> </span><span class="kn">import</span> <span class="n">CombinatorialPurgedCV</span><span class="p">,</span> <span class="n">cross_val_predict</span>
<span class="kn">from</span><span class="w"> </span><span class="nn">skfolio.optimization</span><span class="w"> </span><span class="kn">import</span> <span class="n">MeanRisk</span>
<span class="kn">from</span><span class="w"> </span><span class="nn">skfolio.preprocessing</span><span class="w"> </span><span class="kn">import</span> <span class="n">prices_to_returns</span>

<span class="n">prices</span> <span class="o">=</span> <span class="n">load_sp500_dataset</span><span class="p">()</span>
<span class="n">X</span> <span class="o">=</span> <span class="n">prices_to_returns</span><span class="p">(</span><span class="n">prices</span><span class="p">)</span>

<span class="n">pred</span> <span class="o">=</span> <span class="n">cross_val_predict</span><span class="p">(</span><span class="n">MeanRisk</span><span class="p">(),</span> <span class="n">X</span><span class="p">,</span> <span class="n">cv</span><span class="o">=</span><span class="n">CombinatorialPurgedCV</span><span class="p">())</span>
<span class="nb">print</span><span class="p">(</span><span class="n">pred</span><span class="o">.</span><span class="n">summary</span><span class="p">())</span>

<span class="n">portfolio</span> <span class="o">=</span> <span class="n">pred</span><span class="o">.</span><span class="n">quantile</span><span class="p">(</span><span class="n">measure</span><span class="o">=</span><span class="n">RatioMeasure</span><span class="o">.</span><span class="n">SHARPE_RATIO</span><span class="p">,</span> <span class="n">q</span><span class="o">=</span><span class="mf">0.95</span><span class="p">)</span>
<span class="nb">print</span><span class="p">(</span><span class="n">portfolio</span><span class="o">.</span><span class="n">annualized_sharpe_ratio</span><span class="p">)</span>
</pre></div>
</div>
<p>The default parameters of the <code class="docutils literal notranslate"><span class="pre">CombinatorialPurgedCV</span></code> are <code class="docutils literal notranslate"><span class="pre">n_folds=10</span></code> and
<code class="docutils literal notranslate"><span class="pre">n_test_folds=8</span></code>. You may want to choose these parameters to target a number of test
paths and an average training size. The latter depends on the number of observations.
For that, you can use the function <a class="reference internal" href="../generated/skfolio.model_selection.optimal_folds_number.html#skfolio.model_selection.optimal_folds_number" title="skfolio.model_selection.optimal_folds_number"><code class="xref py py-func docutils literal notranslate"><span class="pre">optimal_folds_number</span></code></a> as shown in the example
<a class="reference internal" href="../auto_examples/clustering/plot_3_hrp_vs_herc.html#sphx-glr-auto-examples-clustering-plot-3-hrp-vs-herc-py"><span class="std std-ref">HRP vs HERC</span></a>.</p>
<div class="highlight-python notranslate"><div class="highlight"><pre><span></span><span class="n">n_folds</span><span class="p">,</span> <span class="n">n_test_folds</span> <span class="o">=</span> <span class="n">optimal_folds_number</span><span class="p">(</span>
    <span class="n">n_observations</span><span class="o">=</span><span class="n">X_test</span><span class="o">.</span><span class="n">shape</span><span class="p">[</span><span class="mi">0</span><span class="p">],</span>
    <span class="n">target_n_test_paths</span><span class="o">=</span><span class="mi">100</span><span class="p">,</span>
    <span class="n">target_train_size</span><span class="o">=</span><span class="mi">252</span><span class="p">,</span>
<span class="p">)</span>

<span class="n">cv</span> <span class="o">=</span> <span class="n">CombinatorialPurgedCV</span><span class="p">(</span><span class="n">n_folds</span><span class="o">=</span><span class="n">n_folds</span><span class="p">,</span> <span class="n">n_test_folds</span><span class="o">=</span><span class="n">n_test_folds</span><span class="p">)</span>
<span class="n">cv</span><span class="o">.</span><span class="n">summary</span><span class="p">(</span><span class="n">X_test</span><span class="p">)</span>
</pre></div>

<section id="multiple-randomized-cross-validation">
<h2>Multiple Randomized Cross-Validation<a class="headerlink" href="#multiple-randomized-cross-validation" title="Link to this heading">#</a></h2>
<p>The <a class="reference internal" href="../generated/skfolio.model_selection.MultipleRandomizedCV.html#skfolio.model_selection.MultipleRandomizedCV" title="skfolio.model_selection.MultipleRandomizedCV"><code class="xref py py-class docutils literal notranslate"><span class="pre">MultipleRandomizedCV</span></code></a> cross‑validation strategy, based on the
“Multiple Randomized Backtests” methodology of Palomar, performs a Monte
Carlo–style evaluation by repeatedly sampling <strong>distinct</strong> asset subsets (without
replacement) and <strong>contiguous</strong> time windows. It then applies an inner walk‑forward
split to each subsample, capturing both temporal and cross‑sectional variability in
performance.</p>
<p>When used with <a class="reference internal" href="../generated/skfolio.model_selection.cross_val_predict.html#skfolio.model_selection.cross_val_predict" title="skfolio.model_selection.cross_val_predict"><code class="xref py py-func docutils literal notranslate"><span class="pre">cross_val_predict</span></code></a>, the object returned is a
<a class="reference internal" href="../generated/skfolio.population.Population.html#skfolio.population.Population" title="skfolio.population.Population"><code class="xref py py-class docutils literal notranslate"><span class="pre">Population</span></code></a> of
<a class="reference internal" href="../generated/skfolio.portfolio.MultiPeriodPortfolio.html#skfolio.portfolio.MultiPeriodPortfolio" title="skfolio.portfolio.MultiPeriodPortfolio"><code class="xref py py-class docutils literal notranslate"><span class="pre">MultiPeriodPortfolio</span></code></a> representing each prediction path.</p>
<div class="highlight-python notranslate"><div class="highlight"><pre><span></span><span class="kn">import</span><span class="w"> </span><span class="nn">numpy</span><span class="w"> </span><span class="k">as</span><span class="w"> </span><span class="nn">np</span>
<span class="kn">from</span><span class="w"> </span><span class="nn">skfolio.datasets</span><span class="w"> </span><span class="kn">import</span> <span class="n">load_sp500_dataset</span><span class="p">,</span> <span class="n">load_factors_dataset</span>
<span class="kn">from</span><span class="w"> </span><span class="nn">skfolio.model_selection</span><span class="w"> </span><span class="kn">import</span> <span class="n">WalkForward</span><span class="p">,</span> <span class="n">MultipleRandomizedCV</span><span class="p">,</span> <span class="n">cross_val_predict</span>
<span class="kn">from</span><span class="w"> </span><span class="nn">skfolio.preprocessing</span><span class="w"> </span><span class="kn">import</span> <span class="n">prices_to_returns</span>

<span class="n">prices</span> <span class="o">=</span> <span class="n">load_sp500_dataset</span><span class="p">()</span>
<span class="n">X</span> <span class="o">=</span> <span class="n">prices_to_returns</span><span class="p">(</span><span class="n">prices</span><span class="p">)</span>

<span class="n">cv</span> <span class="o">=</span> <span class="n">MultipleRandomizedCV</span><span class="p">(</span>
    <span class="n">walk_forward</span><span class="o">=</span><span class="n">WalkForward</span><span class="p">(</span><span class="n">test_size</span><span class="o">=</span><span class="mi">3</span><span class="p">,</span> <span class="n">train_size</span><span class="o">=</span><span class="mi">6</span><span class="p">,</span> <span class="n">freq</span><span class="o">=</span><span class="s2">"WOM-3FRI"</span><span class="p">),</span>
    <span class="n">n_subsamples</span><span class="o">=</span><span class="mi">100</span><span class="p">,</span>
    <span class="n">asset_subset_size</span><span class="o">=</span><span class="mi">3</span><span class="p">,</span>
    <span class="n">window_size</span><span class="o">=</span><span class="mi">2</span><span class="o">*</span><span class="mi">252</span><span class="p">,</span>
<span class="p">)</span>

<span class="n">pred</span> <span class="o">=</span> <span class="n">cross_val_predict</span><span class="p">(</span><span class="n">MeanRisk</span><span class="p">(),</span> <span class="n">X</span><span class="p">,</span> <span class="n">cv</span><span class="o">=</span><span class="n">cv</span><span class="p">)</span>
<span class="nb">print</span><span class="p">(</span><span class="n">pred</span><span class="o">.</span><span class="n">summary</span><span class="p">())</span>

<span class="n">portfolio</span> <span class="o">=</span> <span class="n">pred</span><span class="o">.</span><span class="n">quantile</span><span class="p">(</span><span class="n">measure</span><span class="o">=</span><span class="n">RatioMeasure</span><span class="o">.</span><span class="n">SHARPE_RATIO</span><span class="p">,</span> <span class="n">q</span><span class="o">=</span><span class="mf">0.95</span><span class="p">)</span>
<span class="nb">print</span><span class="p">(</span><span class="n">portfolio</span><span class="o">.</span><span class="n">annualized_sharpe_ratio</span><span class="p">)</span>
</pre></div>
