	<div   class='main_color container_wrap_first container_wrap sidebar_right' style=' '  ><div class='container' ><main  role="main" itemscope="itemscope" itemtype="https://schema.org/Blog"  class='template-page content  av-content-small alpha units'><div class='post-entry post-entry-type-page post-entry-3040'><div class='entry-content-wrapper clearfix'><div class="flex_column av_one_full  flex_column_div av-zero-column-padding first  avia-builder-el-0  avia-builder-el-no-sibling  " style='border-radius:0px; '><div  style='padding-bottom:10px; ' class='av-special-heading av-special-heading-h1  blockquote modern-quote  avia-builder-el-1  el_before_av_textblock  avia-builder-el-first  '><h1 class='av-special-heading-tag '  itemprop="headline"  >MLFinLab on PyPi Index</h1><div class='special-heading-border'><div class='special-heading-inner-border' ></div></div></div>
<section class="av_textblock_section "  itemscope="itemscope" itemtype="https://schema.org/BlogPosting" itemprop="blogPost" ><div class='avia_textblock  '   itemprop="text" ><p><img fetchpriority="high" decoding="async" class="aligncenter size-medium wp-image-19488026" src="http://www.quantsportal.com/wp-content/uploads/2019/03/logo_high_resolution-225x300.png" alt="" width="225" height="300" /></p>
<p style="text-align: center;">Finally our package MLFinLab has been released on the <a href="https://pypi.org/project/mlfinlab/">PyPi index</a>.</p>
<pre style="text-align: center;">pip install mlfinlab</pre>
<p><b>MLFinLab</b><span style="font-weight: 400;"> is a “living and breathing” project in the sense that it is continually enhanced with new code from the chapters in the Advanced Financial Machine Learning book. We have built this on lean principles with the goal of providing the greatest value to the quantitative community.  Currently, the package contains code from the following chapters:</span></p>
<p><span style="font-weight: 400;">Chapter 2: Financial Data structures:</span></p>
<p><span style="font-weight: 400;">The concepts espoused in this chapter are critical for the success of a quantitative program but they are also difficult and tedious because they require raw tick data and efficient implementations of the sampling techniques. We have taken special care and thought to write code that is fast and allows users with low (RAM) memory to transform large csv files (25 gigs and up) to the desired data structure.</span></p>
<p><span style="font-weight: 400;">We thank</span><a href="https://www.linkedin.com/in/proskurinolexandr/" target="_blank" rel="noopener"> <span style="font-weight: 400;">Alexandr Proskurin</span></a><span style="font-weight: 400;">, </span><span style="font-weight: 400;">a core contributor for implementing the information-driven data structures mentioned in the book, namely the imbalance and run bars. He is providing finishing touches to the ETF trick.  It will be released soon.</span></p>
<p><span style="font-weight: 400;">Chapter 3: Labeling</span></p>
<p><span style="font-weight: 400;">This section covers Triple Barrier Labeling and Meta-Labeling techniques. Initially, we had many questions regarding meta-labeling and have provided</span><a href="https://github.com/hudson-and-thames/research/tree/master/Chapter3" target="_blank" rel="noopener"> <span style="font-weight: 400;">3 notebooks</span></a><span style="font-weight: 400;"> in the research repository that expand on the concept.</span></p>
<p><span style="font-weight: 400;">The code in this chapter also relies on Chapter 20: Multiprocessing and Vectorization. We have added the multiprocessing engine to the package.</span></p>
<h2>Current Developments</h2>
<p>Chapter 4: Sample Weights<br />
Alex plans to do this section as soon as he has finished the ETF trick.</p>
<p>Chapter 5: Fractional Differentiated Features<br />
Ashutosh is porting over some of the code we used in our previous project.</p>
<p>Chapter 7: Cross Validation in finance<br />
Wenjie Zheng is looking into this.</p>
<p>Chapter 10 &amp; 17: Bet sizing &amp; Structural Breaks<br />
Ashutosh and Jacques will be working on this section as it forms part of our masters research project.</p>

<h2><span style="font-weight: 400;">Installation:</span></h2>
<h3><span style="font-weight: 400;">For users:</span></h3>
<p><span style="font-weight: 400;">The package can be installed from the PyPi index via the console:</span></p>
<ol>
<li style="font-weight: 400;"><span style="font-weight: 400;">Launch the terminal and run: pip install mlfinlab</span></li>
<li style="font-weight: 400;"><span style="font-weight: 400;">Example of the code being used in notebooks can be found here: </span><a href="https://github.com/hudson-and-thames/research" target="_blank" rel="noopener"><span style="font-weight: 400;">Research</span></a></li>
</ol>
<h3><span style="font-weight: 400;">For Developers:</span></h3>
<p><span style="font-weight: 400;">Clone the package repo to your local machine then follow the steps below.</span></p>
<h4><span style="font-weight: 400;">Installation on Mac OS X and Ubuntu Linux</span></h4>
<ol>
<li style="font-weight: 400;"><span style="font-weight: 400;">Make sure you install the latest version of the Anaconda 3 distribution. To do this you can follow the install and update instructions found on this link: </span><a href="https://www.anaconda.com/download/#mac" target="_blank" rel="noopener"><span style="font-weight: 400;">https://www.anaconda.com/download/#mac</span></a></li>
<li style="font-weight: 400;"><span style="font-weight: 400;">Launch a terminal</span></li>
<li style="font-weight: 400;"><span style="font-weight: 400;">Create a New Conda Environment. From terminal: conda create -n python=3.6 anaconda accept all the requests to install.</span></li>
<li style="font-weight: 400;"><span style="font-weight: 400;">Now activate the environment with source activate .</span></li>
<li style="font-weight: 400;"><span style="font-weight: 400;">From Terminal: go to the directory where you have saved the file, example: cd Desktop/mlfinlab/.</span></li>
<li style="font-weight: 400;"><span style="font-weight: 400;">Install Python requirements, by running the command: pip install -r requirements.txt</span></li>
</ol>
<h4><span style="font-weight: 400;">Installation on Windows</span></h4>
<ol>
<li style="font-weight: 400;"><span style="font-weight: 400;">Download and install the latest version of Anaconda 3</span></li>
<li style="font-weight: 400;"><span style="font-weight: 400;">Launch Anaconda Navigator</span></li>
<li style="font-weight: 400;"><span style="font-weight: 400;">Click Environments, choose an environment name, select Python 3.6, and click Create</span></li>
<li style="font-weight: 400;"><span style="font-weight: 400;">Click Home, browse to your new environment, and click Install under Jupyter Notebook</span></li>
<li style="font-weight: 400;"><span style="font-weight: 400;">Launch Anaconda Prompt and activate the environment: conda activate </span></li>
<li style="font-weight: 400;"><span style="font-weight: 400;">From Anaconda Prompt: go to the directory where you have saved the file, example: cd Desktop/mlfinlab/</span></li>
<li style="font-weight: 400;"><span style="font-weight: 400;">Install Python requirements, by running the command: pip install -r requirements.txt</span></li>
</ol>
<h4><span style="font-weight: 400;">How To Run Checks Locally</span></h4>
<p><span style="font-weight: 400;">On your local machine open the terminal and cd into the working dir.</span></p>
<ol>
<li style="font-weight: 400;"><span style="font-weight: 400;">Code style checks: ./pylint</span></li>
<li style="font-weight: 400;"><span style="font-weight: 400;">Unit tests: python -m unittest discover</span></li>
<li style="font-weight: 400;"><span style="font-weight: 400;">Code coverage: bash coverage</span></li>
</ol>
