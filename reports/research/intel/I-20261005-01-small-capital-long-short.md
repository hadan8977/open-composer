## 一页结论

**推荐合同试 3 种做法（前两种是主角，第三种是便宜的对照）：**

| # | 做法 | 一句话 | 判定（均为我的提议值，业界没有通用阈值，见第四节） |
|---|---|---|---|
| R1 | **集中版两步法**：每边按目标权重绝对值取前 K 只（K 随资金，$5 万 ≤200），各边总额按原值缩放回去，空头整股取整、多头碎股，取整后用 SPY（或 SMH）按实现的 beta 重新对冲，净美元偏离用多头缩放消掉 | 基线。便宜，T-71 已算过可行性 | 同波动夏普保留率 ≥0.80；对连续目标的年化跟踪误差 ≤ 0.25×策略波动；空头敞口比 ≥0.90、相对 L1 ≤30%、净美元偏离 ≤5%（沿用 T-71 的 V2） |
| R2 | **精确法对照**：同样的 K，但"选名 + 整手"一起做混合整数线性规划（HiGHS，线性 L1 目标，二进制基数约束） | 回答"精确法比两步法多保住多少"；我的探针里无基数版单日求解 1–3 秒（第二节），带基数约束的版本待测 | 相对 R1 的同波动夏普增量与敞口比增量；单日求解时间 ≤120 秒（超时取当前可行解并记录 gap） |
| R3 | **下界对照**：丢掉空头腿，只留多头加 SPY 对冲（Blitz 等 2020 的思路）。F2 另做"指数相对少配"的**可行性计数**（只数，不做收益） | R1/R2 必须赢过它才值得保留空头腿 | 同 R1 的两个主指标；F2 少配只报"空头名字里有多少落在指数成分内、超过指数权重的比例" |

**判定里必须带的安慰剂**：同一个 K 下随机选名（不按权重）。R1 没赢过随机选名，说明保住的不是信号而是敞口。

**最强的证据（三条）**
1. **精确法在规模上走不通，启发式够用**：Murray & Shek 2012（全文已读）在 3,000 选 15 的实例上，CPLEX 跑 25,200 秒得 −12.304，成功截断启发式 36 秒得 −12.084（差 1.8%，CPLEX 自己也没证最优）。我们的目标是线性 L1，没有稠密协方差，难点小得多：我的探针里 HiGHS 对 709 只空头的整股 MILP 只要 1–3 秒。
2. **取整的瓶颈是"每只名字不足一股"，不是求解器**：同一个探针里，$5 万档 709 只空头目标中，四舍五入有 419 只为 0 股，精确 MILP 仍有 352 只为 0 股（敞口比从 0.73 拉到 0.98，靠的是把少数名字放大，L1 误差反而从 0.497 升到 0.540）。杠杆是**减少名字（集中）**，这支持 R1 为基线。
3. **约束越多信息损失越大**有成文的量化：Clarke、de Silva、Thorley 2002（摘要已读，数字来自 Institutional Investor 2002 的报道）：换手限 50% 时转移系数 0.73；再加禁空和市值中性降到 0.3。但我的探针显示**直接拿权重相关当转移系数没用**：F1 在 $5 万和 $10 万档，完整整股取整、前 100/200/300 集中版相对完整目标的权重相关全部 ≥0.999。必须改用收益口径（跟踪误差、同波动夏普）。

**没有证据支撑的部分要说清**：小资金整股多空组合没有找到任何可核验的公开实盘记录（证据档 0）；"空头换指数对冲"保住多少阿尔法没有现成数字；F2 的"指数相对少配"在我们 1,784 只宇宙里能覆盖多少空头未知。

## 二、开源求解器

- cvxpy 官方求解器表（`cvxpy-solver-features.txt`，2026-10-05 取）：CBC、GLPK_MI、SCIPY、HiGHS 的混合整数**只支持线性**（表尾注 `(*) Mixed-integer LP only`）；SCIP 支持二次和二阶锥的混合整数。HiGHS 文档：MIP 求解器是分支切割法，"largely single-threaded"，多线程原型 2026-02 完成、尚未发布。
- 本机现状（只读检查）：`.venv` 里 cvxpy 1.9.3，已装求解器 CLARABEL、SCS、SCIPY、HIGHS、OSQP；**没有 SCIP、CBC**，装包不在本任务范围。结论：线性 L1 目标 + 整数变量，用已装的 HiGHS 就够；要二次目标（跟踪误差）才需要 SCIP，装包是单独的决定。
- 公开基准：Mittelmann 的 MIPLIB2017 基准（2026-07-07 版，240 个实例，2 小时限制，Ryzen 9 5900X、12 线程，`mittelmann-milp.txt`）：解出数 COPT 219、HiGHS 并行版 192、HiGHS 1.15.0 158、SCIP 136；缩放几何平均时间以 COPT 为 1：HiGHS 7.55、SCIP 9.93。该页没有 CBC。含义：免费求解器里 HiGHS 领先 SCIP，但比商业求解器慢 5–10 倍；这是通用 MIPLIB 数据，**不是**我们的问题。
- **我们这个规模的单日求解时间（我的探针，临时脚本未保存，代码见附录）**：F1 目标 `reports/paper/book/quant1/targets/2026-10-02.json` 的 709 只空头，scipy 1.17.1 的 `milp`（HiGHS），目标 `min Σ|n_i·p_i − T_i|`，约束实现的空头总额在 [0.98, 1.00]×目标总额，n_i 非负整数，限时 60 秒：

  | 资金 | 四舍五入（T-71 同口径）空头敞口比 / L1 / 0 股名字 | MILP 空头敞口比 / L1 / 0 股名字 | MILP 用时 / 相对 gap |
  |---|---|---|---|
  | $5 万 | 0.730 / 0.497 / 419 | 0.980 / 0.540 / 352 | 2.8 秒 / 6e-5 |
  | $10 万 | 0.893 / 0.315 / 287 | 0.980 / 0.323 / 258 | 1.2 秒 / 9e-5 |

  四舍五入的数字与 T-71 报告逐位一致（59.1%、40.5% 的零股比例复算相同）。**带基数约束（二进制 z_i，Σz≤K）、1,784 只多空一起、K≈200 的求解时间：待测。** 探针的限制：只是空头腿；0.98 的敞口下限是我设的；没有预注册；MILP 的 L1 比四舍五入还高，是因为敞口下限逼它把少数名字放大，不是求解失败。

## 三、执行：多头碎股当日单 + 整股竞价单的拆分

没有找到任何人公开做过这种拆分（证据档 0）。能核实的事实：

1. **碎股只能下 day 单**。Alpaca 订单文档的订单类型—时效表里，碎股（美元名义）一栏 GTC、IOC、FOK、**OPG、CLS 全是 No**，只有 DAY 是 Yes（`alpaca-orders-doc.txt`）；碎股文档同（`alpaca-fractional-doc.txt`：time in force = Day）。整股一栏的 OPG、CLS 标 `Yes*`，表注"带 * 的时效请联系销售"。**我们账户能否直接用 OPG/CLS 没有核实**；如果 v1.2 的整股腿本来就计划用竞价单，这一条要先问清（T-20 审计可能已覆盖，待核）。
2. **同一张单里整股和碎股混合时不会拆**：Alpaca 工作人员 2025-03-24 在论坛答复：碎股部分总是由 Alpaca 自己成交，整股部分路由到执行伙伴；数量 >1 股时，碎股按整股部分的成交价成交；数量 <1 股时按当前 NBBO（买用卖一、卖用买一）成交（`alpaca-forum-fractional-order-execution.txt`）。所以"整股走竞价、碎股走当日单"必须是**两张独立的单**，两张单价格基准不同。
3. **价差来源有三层**：整股竞价按上市交易所竞价成交价；碎股 15:50 的 day 市价单按 NBBO 买卖价成交，外加 15:50 到 16:00 的价格漂移。多头碎股与空头整股竞价单的价差差异会直接变成净美元偏离和 beta 误差，这部分我没有数字，要靠成交对账实测。
4. **收盘竞价截止时间**：NYSE 市价收盘单（MOC）和限价收盘单（LOC）到 15:50 前可录入、修改、撤销；15:50 之后只能录入对冲当时"显著失衡"一侧的反向单，且不能再修改撤销（NYSE 收盘流程说明书 `nyse-closing-process-fact-sheet.txt`，一手来源）。Nasdaq 同为 15:50（只读搜索摘要）。**Alpaca 自己的 CLS 截止时间没找到**，待核。
5. **模拟盘测不到竞价**：Alpaca 工作人员 2024-08-21 写明，模拟盘的 MOO 被当作普通市价单，在开盘报价成交（买用卖价、卖用买价），实盘按上市交易所开盘竞价价成交（`alpaca-forum-moo-worse-than-open.txt`）；实盘的开盘价也可能因多个交易所各有开盘竞价而与"Google 开盘价"不同（`alpaca-forum-opg-not-filled-at-open.txt`）。模拟盘文档还写明：订单数量不检查 NBBO 深度；可成交时有 10% 概率只部分成交、大小随机、余量再评估；模拟盘不收借券费（实盘收）（`alpaca-paper-trading-doc.txt`）。**含义**：10-15 起的 5 万美元模拟盘无法验证竞价腿的成交价，也低估难借券成本（ETB 实盘 $0，T-71 已核）。
6. **建议**：小资金版整本都用 day 单（整股和碎股可放同一张多头单，同价成交），在同一个时点（例如 15:50 前后）发出，成交价口径用实际成交价；竞价腿放到"目标规模"阶段再单独设计。这样与模拟盘撮合方式一致，不引入模拟盘测不到的路径。这是我的建议，不是文献结论。

## 四、怎么判（问题 3）

业界对"小资金版是否保住了原策略"**没有公开的通用阈值**。下面区分"有出处的口径"和"我的提议值"：

| 指标 | 口径来源 | 阈值 |
|---|---|---|
| 同波动夏普差的显著性 | Ledoit & Wolf 2008，J. Empirical Finance 15(5)，850–859（`ledoit-wolf-2008-sharpe-test.txt`，摘要和引言已读）：Jobson–Korkie/Memmel 检验在厚尾或时间序列相关时失效，改用**学生化时间序列自助法**对夏普之差建置信区间，零不在区间内才判不同 | 出处只给方法，不给阈值 |

## 附录：探针代码（内存运行，未保存脚本；`.venv/bin/python`，`ulimit -v` 限内存）

```python
import json, time, numpy as np
from scipy.optimize import milp, LinearConstraint, Bounds
from scipy.sparse import hstack, vstack, identity, csr_matrix
d = json.load(open('reports/paper/book/quant1/targets/2026-10-02.json'))
w, px = d['weights'], d['reference_prices']
sy = [s for s in w if w[s] < 0 and s in px]
W = np.array([-w[s] for s in sy]); P = np.array([px[s] for s in sy])
for C in (50e3, 100e3):
    T = W * C; tot = T.sum(); N = len(sy)
    n0 = np.floor(T / P + 0.5)                       # 四舍五入（T-71 口径）
    c = np.r_[np.zeros(N), np.ones(N)]               # 变量 [n, e]，e_i >= |n_i p_i - T_i|
    A = vstack([hstack([csr_matrix(np.diag(P)), -identity(N)]),
                hstack([-csr_matrix(np.diag(P)), -identity(N)]),
                csr_matrix(np.r_[P, np.zeros(N)].reshape(1, -1))])
    ub = np.r_[T, -T, tot]; lb = np.r_[-np.inf * np.ones(2 * N), 0.98 * tot]
    res = milp(c, constraints=LinearConstraint(A, lb, ub),
               integrality=np.r_[np.ones(N), np.zeros(N)],
               bounds=Bounds(np.zeros(2 * N), np.r_[np.ceil(T / P) + 2, np.inf * np.ones(N)]),
               options={'time_limit': 60})
```
