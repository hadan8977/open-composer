## Feasibility against our free data (why 2-5 are not queued)

- **#2 (option-implied ML)**: we already ran the local probe. `dir:alpaca_free_options_iv_signals` (`not_executable`, updated 2026-09-23) found Alpaca's free options data has **no real historical quotes** — the "quotes" endpoint 404s, so any IV is reconstructed from sparse last trades: 31-39% coverage, an IV-spread mean of the *wrong sign* versus the literature, standard deviation 2-5x too wide, and negative day-to-day autocorrelation consistent with bid/ask bounce, not signal. Arxiv 2608.26115's own headline (predictability "substantially weaker post-2023," exactly our window) makes this a low-prior candidate even before the data blocker; the data blocker alone is sufficient to not queue it. No new registry row: I checked this is the same underlying construct as the existing entry, just a newer paper: added as evidence to the existing row would be more truthful than a new id, but per the task's instruction to log "each candidate," a new row `dir:option_implied_crash_risk_xgboost_2026` is added below, explicitly cross-referencing and not duplicating the existing verdict.
- **#3 (earnings-call transcripts)**: our local `data/raw/earnings_text/` (335MB, 1,396 companies) is **8-K press-release exhibits** (`EX-99.1`, confirmed by reading a sample file directly), not verbatim call transcripts with management discussion and analyst Q&A. `dir:llm_earnings_call_transcript_pricing` already established that free batch call-transcript history does not exist and the owner declined to buy it; `dir:earnings_8k_tone_next_day` already tested LLM-scored tone on our press-release text and found it priced at the open once the gap is controlled (t 0.59 vs gap t 4.63), with its own `reopen_if` explicitly naming "call transcripts become available" as the reopening condition — which this candidate's exact data need (`call transcripts`, not press releases) still does not satisfy. The Molinaro paper's *methodology* (trained dense embeddings + CAPM-residual ML regression, as opposed to LLM-prompted tone) is a genuinely different mechanism from what we tested — but it needs data we do not have and have not been authorized to buy.
- **#4 (supply-chain graph + LLM embeddings)**: needs a supply-chain relationship graph (FactSet Revere / Bloomberg-style enterprise data); `dir:alt_data_satellite_app_supply_chain` already found this class of data is enterprise-priced and out of budget. Even ignoring the data gap, the disclosed numbers (54.2% IC hit rate, ambiguous-sign t-stat) are weak on their own terms.
- **#5 (GNN relational models)**: the *data* problem is smaller here — we could construct a correlation- or sector-based graph from data we already have without new acquisition — but the *evidence* problem is not: every source found tests on 30-500-name single-market-index universes, reports accuracy/MSE/ranking metrics rather than disclosed portfolio Sharpe/DD, and none has an independent replication or a live/forward track record. This is exactly the "self-reported author claim, no replication" pattern the mission's skepticism rule asks to discount. Not worth a Modal dollar yet; worth a cheaper next step (a plain correlation-graph baseline compared to our existing rule twin, no GPU, no Modal) only if a future search finds a disclosed live/OOS Sharpe.
- **#6/#7 (formulaic alpha mining GP/RL, MASTER-family transformers)**: both already carry a registry `reopen_if` that requires a published US-equity out-of-sample validation. This session's targeted re-search (four separate queries, arXiv/AAAI/GitHub) found none — every result remains China A-shares or crypto. Modal genuinely removes the *hardware* half of the block (both entries cite "no GPU, 3.9GB RAM, no AVX2" as their `data_needs`/verdict), but per the mission rule against reopening a route without new distinguishable information, the *evidence* half is unmet, so both stay as-is. This is worth restating plainly for whoever reads this next: **the day a genuine US-equity OOS result appears for any of AlphaForge/AlphaGen/AlphaSAGE/AlphaPROBE or MASTER, Modal makes it immediately actionable** — it is now purely a search problem, not a compute problem.
- **#8 (competition methods)**: no disclosed mapping from Jane Street/Optiver/Numerai's anonymized features to real securities exists publicly (by design — these are the firms' proprietary edges). The one transferable lesson (ensemble diversity + neutralization/reversal framing for daily equities, per the delphicalpha survey) is a **feature/method idea for T-20260928-10's multi-source ranker**, not a standalone candidate: it argues for including ensembling and cross-sectional neutralization in that model's candidate grid, which is already partially true (LambdaRank ranking candidates 7-12 in `I-20260928-02`'s prereg already rank rather than regress raw returns).
