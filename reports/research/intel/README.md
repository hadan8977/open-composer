# 情报先行（intel-first）：这个目录是干什么的

2026-09-18 用户的纠正（永久规则）：

> 「你不能每次都偷懒，然后把努力用在没有足够验证和思考的地方……你直接测试的这些 qlib 上的或者别的开源的因子模型，是不是都没有那么新或者验证数据，多久没更新了，又有没有人已经测试过了呢，有没有基于这些做出了比较好的策略分享出来呢……为什么不多了解 10 倍、100 倍、10 步、100 步之后的信息是否存在呢……方向比努力重要。」

## 规则

**任何要花算力的验证之前，先回答四个问题，并把答案写成本目录下的一份情报简报：**

1. **新不新**：这个方法/策略的来源最后一次更新是什么时候？它的基准数字是哪个市场、哪个时间段？（例：Qlib 的 Alpha158 基准是 CSI300 2008–2020，不是美股，也不是近期。）
2. **有没有人验过**：除了原作者，有没有第三方复现？复现结论是什么？如果没有人复现，就直接写"只有作者自己说"。
3. **有没有人已经做出来并分享了**：有没有公开的净值曲线、实盘/模拟盘对账单、可运行的代码仓库？licence 是什么？
4. **在我们这台机器上能不能跑**：3.9 GB 内存、2 核、无 GPU、无 torch；数据只有美股日线 2016–2026、分钟线 2016–2026、SEC 申报、新闻标题、Alpaca 模拟盘（4 倍日内杠杆、可做空、期权 3 级）。需要 tick 数据、期权链历史、期货、亚秒级延迟的，直接判为今天做不了。

然后才允许写假设卡；**每张卡必须有"情报"一节**，引用本目录的简报，并写明"最便宜的决定性测试"是什么、要跑多久。

## 顺序

情报简报 → 假设卡（含情报节与否定条件）→ 最便宜的决定性测试 → 只有活下来的才投入算力做完整评估 → 教训写回 `reports/research/lessons/`。

优先复现别人已发表的结果，而不是发明变体；发明变体只在复现成功之后做。
