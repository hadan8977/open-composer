# P1 中频股票引擎：项目笔记

本文件除“实验清单”和“规模曲线”两节外，都是 `docs/plan-v2-2026-10-05.zh.md` 的摘录，每段注明出处章节。两节生成内容由 `uv run python scripts/program_pages.py render` 从 `experiments.json` 和 `depth_curve.jsonl` 重新生成，不要手改标记之间的内容。执行轮取下一个实验：`uv run python scripts/program_pages.py next p1-midfreq`。

## 目标

在 v1.2 的风险模型和优化器上，加一条成本感知的残差多信号短期统计套利腿。范围是最流动的 500–1000 只，持有 3–10 个交易日，部分调仓；判定标准是同波动下账户级净夏普提高。（出处：计划第 3.1 节“目标”）

多空两边：空头只做容易借的股票，借券成本和替代股息进成本模型；总杠杆在 Alpaca 保证金限额内（初始 50%，维持 25%，集中持仓 50%），由风险预算定。（出处：计划第 3.1 节）

执行时点按阶段 3 的同信息比较定。开盘改收盘不是白捡的：省下的价差要和一个交易时段的信号衰减相抵。（出处：计划第 3.1 节）

成本是主约束：最流动十分位收盘单边成本约 1.9–2.7bp；每天全换手每条腿要有每日约 3.8–5.4bp 的毛 alpha 才打平，持有 5 日只要 0.8–1.1bp/日。开盘半价差中位 4.56bp，收盘 1.44bp（最流动十分位，本地实测）。（出处：计划第 3.1 节“对利润的路径”）

## 已知结论

- 浅做必败：Avellaneda–Lee 式单信号 PCA 加 OU 阈值，在 5bp 成本下净夏普为 −2.5 到 −7.1（Attention Factors 表 2）；我们以前否定的中频线多数是这种单信号、固定成本的浅做，不能当作“这一类整体否定”。（出处：计划第 3.1 节“别人怎么做”）
- 公开的最好结果：DLSA 约 550 只、2002–2016、净夏普 0.94–1.24；Attention Factors 500 只、1998–2021、净夏普 1.58–2.28。两者都是作者自己的回测，2022 年以后没有净值证据，这是最大的缺口，阶段 1 来补。（出处：计划第 3.1 节）
- 本地日内线都是单信号浅测：SPY 日内动量 2016–2026 夏普 0.30；开盘区间突破的收益被随机方向安慰剂拿回 92.7%。按 P-1，这些只说明“浅做不行”，不能否定日内这一类。（出处：计划第 3.1 节）
- 功效：阶段 1 在近期窗口上，按原文净夏普约 1.0 算，单看近期窗口的检出概率约 38%，所以只设“全部深度点都 ≤ 0”这种明显失败的停止条件。（出处：计划第 3.1 节“功效”、第 1 节功效表）
- 最低有效深度八条：时点宇宙（含退市）；至少 5 个低相关短期信号合成或学习式残差信号；对市场、行业、风格取残差；成本进目标函数；部分调仓加缓冲带；滚动重训（约 4 年窗口，约每 125 个交易日一次，purge 等于标签期）；收盘或竞价执行；预注册、DSR、安慰剂并按对 v1.2 的边际贡献判。（出处：计划第 3.1 节“最低有效深度”）
- “复现”指同一方法在我们数据上重现原文的相对结论：学习式信号胜过 OU 基准；IPCA 残差胜过 PCA 残差；加摩擦惩罚后换手下降。（出处：计划第 3.1 节）
- 适用状态：截面离散度和流动性正常。失效信号：拥挤去杠杆、截面离散度骤降、实现价差持续大于模型的 1.5 倍、前向 z < −2；触发一个减半，两个停；半年滚动复核。（出处：计划第 3.1 节）
- 漏掉的代价高，否定必须满足 P-1 的五条；误报的代价用影子和模拟盘拦住，实盘只用试点规模。（出处：计划第 3.1 节）

### 台账字段

`depth_curve.jsonl` 每行一个 JSON 对象，字段如下，缺一不可；曲线上每个点都计入试验总数（计划第 1 节 P-1）：

- `experiment_id`：实验 id，必须在 `experiments.json` 里存在；
- `depth_point`：深度点，例如“宇宙 500 只”“持有 5 日”；
- `metric`：指标名，例如净夏普、边际 IC；
- `value`：数值（原样记录，不四舍五入后再记）；
- `cumulative_trials`：到该点为止本项目累计试验数（整数，不小于 1）；
- `recorded_utc`：写入时间，`YYYY-MM-DD HH:MM`，用 `date -u` 取，不手打；
- `artifact`：产物路径，数值可在该文件里核对。
