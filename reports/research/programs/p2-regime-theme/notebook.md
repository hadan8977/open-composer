# P2 状态与主题风险引擎：项目笔记

本文件除“实验清单”和“规模曲线”两节外，都是 `docs/plan-v2-2026-10-05.zh.md` 的摘录，每段注明出处章节。两节生成内容由 `uv run python scripts/program_pages.py render` 重新生成，不要手改标记之间的内容。执行轮取下一个实验：`uv run python scripts/program_pages.py next p2-regime-theme`。

## 目标

解决压力期夏普低和押注半导体的问题，分四步：主题风险预算（把半导体和 AI 当一个风险单元，设上限或对冲，不依赖预测）；在线状态层（带持续性的状态模型，按模型轴做深）；用周期指标做条件器和监控面板；拥挤度因子，作为监控面板。（出处：计划第 3.2 节“目标”）

专业做法是先限制暴露，再识别状态，而不是先预测周期。（出处：计划第 3.2 节“为什么这样排”）

## 路线图

阶段表（出处：计划第 3.2 节“阶段和日期”）：

- 阶段 1 主题风险预算：半导体主题因子（SMH 对 SPY 正交化），ETF 穿透到个股，主题边际风险贡献上限；上限版和对冲版；回放 2024-07、2025-04、2026-07 三次冲击，用其他行业做安慰剂。10-05 至 10-07。判定：同波动口径，加上限或对冲后再加杠杆回原来的波动，近期夏普下降不超过 0.10（开跑前写定）；同时报压力期夏普、预期短缺、三次回放回撤和所需总杠杆。上限是风险政策，结果直接成为实盘试点的集中度上限。
- 阶段 2 状态层：模型轴（跳跃模型、2 状态隐马尔可夫、高斯混合、现有“200 日线加 VIX 三档”）；输入轴（3、4、6 个，另加 Gidea–Katz 持续同调景观范数的因果版拓扑变体）；持续性惩罚 3 档；按轴扫约 10 个规格，作为 S1–S3、C2 的敞口乘数，和同敞口基线、安慰剂比。10-08 至 10-13。全部深度点都不胜过同敞口基线，才写“未见增量”；回撤、预期短缺、切换次数分开报。
- 阶段 3 周期条件器：带发布日期的月度面板（韩国出口含前 20 天、台湾外销订单、台积电月营收、SIA、新订单和库存），PLS 或岭回归聚合。10-21 起。输入数 2、4、8 三个深度点，前后两半样本都没有增量，才只留作监控面板。
- 阶段 4 拥挤度：估值、成交量、波动、动量、空头仓位五个输入的个股拥挤得分，加 comomentum；只做监控面板和事件描述，不设停止条件。10-21 起。

并入组合：阶段 2–3 通过的规则先做 8–12 周只记日志的影子运行，再并入配置第二版（T-58）。阶段 1 的上限直接用于试点。（出处：计划第 3.2 节）

预测市场线（机主 10-02 开题，归入 P2 和 P1 阶段 2a）：H1 Kalshi 宏观发布不确定性——继续积累，攒够约 60 个发布日后重开；Polymarket 财报超预期赔率——改标“未到深度”，作为 P1 阶段 2a 财报事件的一个特征；中期选举控制权赔率“Trump trades”——前向影子到 11-04 之后定；polyledger——观察。（出处：计划第 3.2 节“预测市场线”）

## 已知结论

- 状态模型：统计跳跃模型（Shu–Yu–Mulvey 2024，标普 500，1990–2023，含 10bp 成本和 2 天延迟）把夏普从 0.48 提到 0.68，回撤从 −55% 降到 −27%，换手 44%；同表隐马尔可夫模型换手 141%，年化收益低于买入持有；一个独立复现只复现了回撤减半，所以它主要是回撤控制。（出处：计划第 3.2 节）
- 动量崩溃：Barroso–Santa-Clara 的波动缩放几乎消除崩溃；择时在样本外站得住的是“多个预测量聚合后降维、小剂量”，不是单指标。（出处：计划第 3.2 节）
- 半导体读数（2026-10-04，已对快照核实）：基本面在历史极值并仍在加速，价格增速已经回落，7 月 SOX 一个月跌 21% 是拥挤加杠杆造成的；周期指标只能当条件器，不能当买卖信号。（出处：计划第 3.2 节）
- 最低有效深度：3–6 个互补输入，2 个状态，持续性惩罚在滚动窗口里验证；拟合至少 12 年，评估至少 25 年，含至少三次崩溃；在线推断，延迟 1–2 天，成本 5–10bp；和同敞口基线、循环位移安慰剂比较。我们的 SIP 数据从 2016 年起，要用免费长历史拟合、SIP 验证。（出处：计划第 3.2 节）
- 功效：2024 年以来大的状态切换很少，近期窗口检验状态层的功效低，所以判定以“不劣于同敞口基线”为主，长历史只作诊断，影子运行补前向证据。（出处：计划第 3.2 节）
- 适用状态和失效信号：状态规则在切换过快时失效；失效信号是一个季度内切换超过预注册次数，或 6 个月滚动夏普低于同敞口基线。（出处：计划第 3.2 节）
- 代价：漏掉的代价中等，主要影响回撤；误报的代价高，状态择时容易过拟合，所以必须有同敞口基线、安慰剂和影子。（出处：计划第 3.2 节）
- Polymarket 财报赔率：赔率本身有信息（AUC 0.81），但最小可检出周 IC 是 0.110、观测值 0.019，功效不足；中期选举线近期窗口没有复现原文（净夏普 −1.20，t −1.24）。（出处：计划第 3.2 节“预测市场线”）

### 台账字段

`depth_curve.jsonl` 每行一个 JSON 对象，字段如下，缺一不可；曲线上每个点都计入试验总数（计划第 1 节 P-1）：

- `experiment_id`：实验 id，必须在 `experiments.json` 里存在；
- `depth_point`：深度点，例如“输入 4 个”“持续性 λ=50”；
- `metric`：指标名，例如同敞口净夏普差、压力期预期短缺；
- `value`：数值（原样记录，不四舍五入后再记）；
- `cumulative_trials`：到该点为止本项目累计试验数（整数，不小于 1）；
- `recorded_utc`：写入时间，`YYYY-MM-DD HH:MM`，用 `date -u` 取，不手打；
- `artifact`：产物路径，数值可在该文件里核对。
