# Step 10 Wave 3: 预注册组合（逆波动率，两个 sleeve）

计划：`docs/plan-step-10-mechanism-supplementation-2026-09-03.zh.md` 第 6 节（规则预注册，执行者不得调整）。
证据 JSON（本地，未入库）：`reports/research/control/step10-w3-combination-2026-09.json`。
评估脚本（已入库）：`scripts/evaluate_step10_wave3_combination.py`。

## 结论

**组合不通过新合同**（8 门过 6，`cagr_excess_vol_matched_benchmark` 与 `sharpe_excess_bil` 仍不过），但这是本轮三个族单独评估里从未出现过的结果：**两个中等相关（ρ=0.41）的 sleeve 组合后，恰好在这两道真正卡住候选的门槛上都比任一单 sleeve 更接近门槛**——Sharpe-ex-BIL 从 F1 的 0.589、F2 的 0.648 提升到组合的 **0.743**；超额 CAGR 从 F1 的 +0.99pp、F2 的 +1.33pp 提升到组合的 **+2.44pp**。分散化确实起作用，只是这一轮起的作用还不够把任何东西送过门槛。

## 1. 入选 sleeve（预注册规则，见下方"执行判断"第 1 条的取舍说明）

三个族各自的最佳候选（"探路遍"里 Sharpe-ex-BIL 最高的一个，与 Wave 1/2 报告一致）：

| 族 | 候选 | Sharpe-ex-BIL | 有效 N | 是否过 0.4 门槛 |
|---|---|---:|---:|---|
| F1 beta 暴露 | C12（QQQ,SMA200,-15%回撤止损） | 0.589 | 1 | 是 |
| F2 跨资产趋势 | lookback=6,top_n=5,equal | 0.648 | 1 | 是 |
| W2 liquid-500 横截面动量 | top_fraction=0.10,月度 | 0.474 | 1 | 是 |

三者都过 Sharpe 门槛。两两 OOS 日收益相关性（在三者共同的 1172 个交易日窗口，2022-01-03 至 2026-09-03 上计算）：

| | F1 | F2 | W2 |
|---|---:|---:|---:|
| **F1** | 1.000 | 0.410 | 0.392 |
| **F2** | 0.410 | 1.000 | **0.710** |
| **W2** | 0.392 | 0.710 | 1.000 |

F2 与 W2 相关性 0.710，超过 ≤0.5 门槛——两者本质上都是"顺势加多头"的动量机制（一个跨资产时序动量，一个大盘股横截面动量），在同一段市场环境里同涨同跌并不意外。三者不能同时入选。

## 2. 执行判断（计划文本未完全钉死，本次决定并记录，不是看结果后调整）

1. **不满足三者互斥相关性时怎么选**：按 Sharpe-ex-BIL 从高到低贪心添加——先接受 F2（0.648，最高），再看 F1，corr(F1,F2)=0.410≤0.5，接受；最后看 W2，corr(W2,F2)=0.710>0.5，拒绝（即使 corr(W2,F1)=0.392 本身是合格的，但 F2 已经先入选，W2 必须同时满足与"全部已入选 sleeve"的两两条件）。这个取舍完全由 Sharpe 排名和预先定好的 0.5 门槛决定，不是试了几种组合挑好看的那个。
2. **DSR 试验数里"各族"的范围**：计划原文"各族有效 N 之和 + 1"没有说清是"入选的族"还是"参与角逐的族"。按更保守的口径读（本轮 Wave 1/2 实际考察过的三个族都算，不管最后有没有被相关性筛掉）：`1(F1) + 1(F2) + 1(W2) + 1 = 4`。选择更保守口径而不是"入选的两个族 + 1 = 3"，与本项目一贯"有歧义时不放宽解读"的原则一致（更大的试验数让 DSR 门槛更难过，不是更容易）。
3. **逆波动率回看期的启动问题**：计划要求"过去 252 日已实现波动率"，但组合的起点（2022-01-03）本身就是三个 sleeve 各自"已经是 OOS"的拼接窗口起点，往前没有更多历史。用等权重顶住前 20 个交易日（沿用本项目 beta 路由已有的 `volatility_lookback_days=20` 惯例），之后用扩张窗口（最多 252 日）算逆波动率——这样组合的样本期仍是完整的 2022-2026 五个日历年，不用因为"要凑满 252 天历史"而牺牲整个 2022 年。
4. **折叠（fold）重建**：组合的原始输入本来就是三个 sleeve 各自"已经是样本外"的拼接流，往前没有可用于训练/拟合的历史区间可喂给 `rolling_origin_folds`——也不需要，因为组合层的逆波动率加权是一条固定规则，不在任何训练窗口上拟合参数，没有"训练/测试"要防的东西。若 `rolling_origin_folds` 真能在这份输入上跑（它跑不了，因为它要求第一个测试年之前有訓練数据，而这里没有），它产出的拼接序列本来就会等于整个输入本身（5 个日历年的输入,每一天都属于某一年的"测试"窗口）——所以直接按日历年（2022/2023/2024/2025/2026）切分组合自己的日收益序列来重建 `oos_fold_returns`，数学上等价于 `rolling_origin_folds` 若无这个结构性障碍时会给出的结果。
5. **组合层的成本压力**：sleeve 之间月末再分配的换手，本次**没有**额外建模交易成本（每个 sleeve 自己的日收益已经包含了该 sleeve 内部的交易成本）。`stress_return_stream` 直接等于 `oos_return_stream`，即把组合层当作对成本不敏感处理——`mechanism_eval` 的新合同本来就不对 `stress_total_return` 设门（只作诊断，`gate_results` 里没有这个键），所以这个简化不影响裁定，但如实记录，不是悄悄假设。

## 3. 组合方式

逆波动率、月末重算、不做优化（计划规定）：58 次权重更新（1 次启动 + 57 个月末），每次用当日为止最多 252 个交易日的已实现波动率算权重，固定权重直到下次月末，逐日盯市。F1（更保守、波动更低）权重区间 0.367-0.899（均值 0.457），F2（波动更高）权重区间 0.101-0.633（均值 0.543）——逆波动率规则按设计给波动更低的 F1 更高权重、给波动更高的 F2 更低权重，与直觉一致。

## 4. 结果（新合同，8 门过 6）

| 指标 | 组合 | F1 单独 | F2 单独 | 门槛 | 组合是否过 |
|---|---:|---:|---:|---:|---|
| `cagr`（原始） | 11.93% | 11.86% | 11.08% | — | — |
| `cagr_excess_vol_matched_benchmark` | **+2.44pp** | +0.99pp | +1.33pp | ≥5pp | 否 |
| `sharpe_excess_bil` | **0.743** | 0.589 | 0.648 | >1.0 | 否 |
| `benchmark_vm_capture_ratio` | 1.090 | 1.116 | 1.058 | ≥1.0 | 是 |
| `benchmark_vm_downside_capture` | 0.750 | 0.536 | 0.782 | ≤1.0 | 是 |
| `mar` | 1.206 | 0.762 | 0.994 | ≥0.6 | 是 |
| `max_drawdown` | -9.89% | -15.58% | -11.14% | ≥-35% | 是 |
| `positive_fold_fraction` | 0.8（4/5 年） | 0.8 | 0.8 | ≥0.6 | 是 |
| `dsr_probability` | 0.706 | 0.770 | — | ≥0.5 | 是 |
| `vol_match_weight`（w） | 0.626 | 0.620 | 0.657 | — | 组合波动率约为 SPY 的 63% |
| `promotion_eligible` | **False** | False | False | — | — |

组合在**每一个已经通过的门槛上都不弱于**两个单 sleeve（`max_drawdown` -9.89% 是三者中最好的，`mar` 1.206 也是最好的），且在两个仍未通过的门槛（超额 CAGR、Sharpe-ex-BIL）上都优于两个单 sleeve 各自的数字——这正是分散化应该有的效果（同样的机制暴露，波动被压低，风险调整后收益提高），只是提高的幅度这次不够跨过 5pp / 1.0 这两道具体的线。旧合同（`kernel-paper-tier-gates.json`，仅参照）下同样 `promotion_eligible=False`（`cagr_excess_qqq=-2.09pp`、`qqq_capture_ratio=0.018`，与两个单 sleeve 一样卡在"绝对值要跟上杠杆化 QQQ"这道对非杠杆策略不公平的老门槛上）。

## 5. 诊断（非门槛）

- **危机窗口**：组合的样本期从 2022-01-04 开始，`CRISIS_WINDOWS` 里只有 2022 全年落在窗口内（2020 疫情崩盘、2018Q4 都在样本期之前，报告里如实标注"no overlap"，不是遗漏）。2022 全年：组合 -8.40%，同期 SPY -18.64%——跌幅约为基准的 45%，与 `vol_match_weight=0.626` 大致吻合。
- **选择后窗口**（2026-07-09 至 2026-09-03，41 个交易日）：组合 CAGR +8.49%，同期 SPY 基准 +25.21%，跑输；但比 F1 同期单独的 -8.23% 好得多（这段时间正是 F2 的强势期，F2 单独选择后 CAGR 曾是 +27.6%，组合把 F1 的近期弱势和 F2 的近期强势混合，落在两者中间）。样本极短，非裁定依据。

## 6. 对 Wave 4 的含义

若这条路线要在未来某周通过：需要一个比这次更强，或者与 F1/F2 相关性比 0.41 更低的第三个 sleeve 补进来（W2 因为和 F2 相关性太高被排除，不是因为它本身弱）。这不是本周要做的决定，留给下一轮方向建议（见 `strategy-iteration-progress-2026-07-01.md` 的负结果记录）。按计划第 7 节，组合本身不通过新合同，因此不触发"多个 spec 并行接入"的产品化路径。
