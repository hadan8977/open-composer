# Brief: rebuild `data/features/daily_broad` 2016-2021 from the repaired archive (pitfall #64)

Written by the interactive session (Opus), 2026-10-06. Light data task: six capped builds (~12 min each) and six checks (~2 min, ~1.6 GB each).

## Why

The 2016-2021 partitions of `data/features/daily_broad` were built on 2026-09-18, before the 10-02 T-20261002-01 archive repair. 2022-2026 have been rebuilt since (2022-2025 on 10-05). The store therefore has a seam at 2021/2022: 48 symbols carry split- or row-level restatements (ALP, BGM, CTSO, ...) and about 4,500 carry dividend-size ones. v1.2 live targets read history from 2024 on and are unaffected. Any research that reads `data/features/daily_broad` across 2021/2022 is affected. Details: `docs/data-layer-pitfalls-and-capabilities.zh.md` item 64.

## Steps

1. Preconditions, checked before each heavy command:
   - not between 18:00 and 00:45 UTC (paper plan/submit window and the 22:45 nightly refresh);
   - no other process above 1 GB (`ps -eo pid,rss,comm --sort=-rss | head`);
   - the refresh lock is free (`flock -n data/live/.refresh.lock true`).

   If any precondition fails, wait or stop and report. Never kill anything.
2. For each y in 2016..2021:

   `scripts/run_capped.sh --mem 1.8G -- uv run python scripts/build_daily_features.py --universe-root data/features/universe_broad --extra-daily-root data/sip-delisted/by_year --out-dir data/features/_rebuild_t0602 --memory-limit 1.0GB --years {y}`

   This is the same command the live driver uses for `daily_broad`.
3. Check each staged partition against the current one with the driver's own code. Write a short driver in /tmp; do not add it to the repo.
   ```python
   from scripts import refresh_equity_book_live as rf
   old = Path(f"data/features/daily_broad/{y}.parquet"); new = Path(f"data/features/_rebuild_t0602/{y}.parquet")
   built = datetime.fromtimestamp(old.stat().st_mtime, UTC)
   rebased = rf.rebased_symbols([(y, built)])          # allow files: one symbol per line
   cut = max(rf._dates_of(old, "trade_date"))           # whole year (not strict_cut: old partitions are closed)
   cmd = rf.check_command(rf.table_by_name("daily_broad"), old, new, cut, out_json, allow_new, allow_old)
   ```
   Run `cmd` under `scripts/run_capped.sh --mem 2.5G --`, then record per year:
   - `pass` and `keys_ok`;
   - the two unallowed key counts;
   - `max_changed_share`;
   - the number of re-based symbols;
   - the top changed symbols.
4. Swap only if all six checks pass:
   - under `flock data/live/.refresh.lock`, copy each current partition to `data/live/backup-refresh/t20261006-02/daily_broad/{y}.parquet` (`cp -p`), then copy the staged file over the current one;
   - confirm the sha256 of each swapped file equals its staged file;
   - remove only `data/features/_rebuild_t0602/` (you created it).

   If any check fails, swap nothing and report the failing years with their samples. Do not widen any allow list and do not change any threshold.
5. Write `reports/research/program/data-refresh-2026-10-01/daily-broad-2016-2021-rebuild.json`:
   - the per-year numbers;
   - the backup paths;
   - the sha256 values;
   - the UTC time, computed inside the script.

   Commit it with pathspec: `git add -f <file> && git commit -m "T-20261006-02 ..." -- <file>`. End the message with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
