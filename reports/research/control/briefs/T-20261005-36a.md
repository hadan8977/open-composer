## 背景

我们是个人 AI 策略工作台，用 Alpaca 模拟盘，只用免费数据。v1.2 是日频的美股多空组合（约 1,800 只股票的宇宙，F1 市场中性多空，F2 是 SPY 加多空叠加层）。Alpaca **不支持碎股做空**，空头只能整股；多头可以碎股，但碎股只能下当日单，不能参加开盘和收盘竞价。T-71 算过（`reports/research/program/capacity-live-2026-10-07/report.md`，先读第二、三、五、六节）：子仓 5 万美元时，F1 约 59% 的空头取整后是 0 股；按标准，整股取整后空头的实现敞口要 ≥ 0.90 目标、相对 L1 误差 ≤ 30%、净美元偏离 ≤ 净值 5%。T-71 第五节已列了几条做法，但多数只读了摘要。

10-09 至 10-14 我们要在 Modal 上构造"小资金版"，10-15 用 5 万美元的模拟账户跑。主审轮 10-08 写合同。你的调研决定合同里试哪几种做法、怎么判。

## 要回答的问题

1. **别人怎么做**。每种做法写：原文（作者、年份、出处、DOI 或网址）、核心做法、报告的效果（跟踪误差、转移系数、夏普损失，样本和口径）、是否有开源实现（仓库、许可证、星数和最近更新，用 GitHub API 取）、我们的适用性。至少覆盖：
   - 基数约束和整手约束的混合整数优化（T-71 第五节第 1、2 条，正文要读到）；
   - 两步法：先连续优化再按规则取整（例如按目标金额排序取前 K 只、随机取整、贪心修正），和精确法比差多少；
   - 转移系数（Clarke、de Silva、Thorley 2002）和"约束越多信息损失越大"的后续研究，用它做预注册指标的做法；
   - 指数相对的"少配代替做空"：直接持有指数成分股（多头可碎股），只在少配幅度超过该股指数权重时才做空，类似 130/30 和 direct indexing 的做法；
   - 小资金量化从业者的公开做法（论坛、博客、开源项目）：多少只股票、多少资金、怎么处理碎股和最小下单额，有没有公开的实盘记录。
2. **开源求解器**：cvxpy 加哪个混合整数求解器（免费可用的，例如 HiGHS、SCIP、CBC），在 1,800 只、K 约 200 的规模上，单日求解要多久（有公开基准就引用，没有就写"待测"）。我们已有 cvxpy。
3. **怎么判**：合同应该用什么指标判断小资金版是否保住了原策略的收益，例如同波动夏普、转移系数、跟踪误差、换手。给出业界常用的口径和阈值，带出处。
4. **执行**：多头碎股部分在 15:50 ET 前后下当日单、整股部分用竞价单，这种拆分有没有人做过，要注意什么（成交价差异、部分成交）。
