   - D = `data/sip/daily` 里 2026 年最大的交易日。D 早于 2026-09-30 就标 `blocked` 后结束。不要自己运行 `scripts/update_sip_archive.py`，它归 crontab 管。

1. **清单**（只读，不写数据）。对上表每张表，只读脚本开头的文档字符串（`sed -n 1,60p`）、`grep -n add_argument`，以及该表目录里的 `_build_manifest*.json`，不要通读仓库。写 `reports/research/program/data-refresh-2026-10-01/inventory.json`，每张表一项：

   - `build_cmd`：只重建 2026 年的命令。参数照抄构建清单或原始构建日志，只改年份或截止日期；
   - `reads_prior_years`、`needs_api_key`（只写变量名，不写值）、`expected_cadence`（daily、weekly、bimonthly、monthly）。

2. **备份**：把每张要重建的 2026 分区，以及会被改写的单文件表和原始归档（`nsi.parquet`、`facts.parquet`、`parsed.parquet` 等）复制到 `data/live/backup-20261001/<原相对路径>`。先算 sha256，记进 `inventory.json` 的 `sha256_before`。
3. **采集**，一次一个来源，各自写日志 `logs/t21_fetch_<来源>.log`：SEC（XBRL、Form 4）、FINRA 日度卖空量、FINRA 半月度空头持仓、Alpaca 新闻。只用现成的采集脚本和它们的增量参数。不要并行采集，SEC 请求频率按脚本自带的限速。需要密钥的脚本自己从 env 文件读，你不要打开、打印或复制 env 文件。认证失败就停掉这个来源，记 `unresolved`。
4. **重建**，按依赖顺序，每步 `scripts/run_capped.sh --mem 1.8G -- uv run python ...`，一次一个，日志 `logs/t21_build_<表>.log`：
   universe_broad → daily_broad → sec_fundamentals（facts，再 daily）→ nsi → insider_broad → short_volume_broad → short_interest → news_attention → alpha101_broad 和 alpha191_broad。
5. **不变性检验**：写 `scripts/check_feature_invariance.py`（新文件）和 `tests/test_check_feature_invariance.py`，测试用小的合成 parquet。
   - 用法：`--new <parquet> --old <备份 parquet> --date-col <列> --cut 2026-09-17 --keys symbol,<date_col> --out <json>`。
   - 只比 `date_col ≤ cut` 的行，输出以下字段：
     - `keys_equal`：两边键集合相同；
     - 每个数值列的 `changed_share`：|新 − 旧| > 1e-9·max(1, |旧|) 的行占比，两边都是 NaN 算相同；
     - `max_changed_share`；改动最多的 20 个 symbol；
     - 新增部分：`n_new_dates`、`last_date`，以及 `coverage_ratio` = 新日期的平均截面行数 ÷ cut 前 20 个日期的平均截面行数。月度、半月度表按自身频率取最近 3 期。
   - **通过**：`keys_equal` 为真，且 `max_changed_share ≤ 0.001`。
   - **不过**：把这张表（以及它改写过的原始归档）从备份恢复，核对 sha256 等于 `sha256_before`，标 `restated`；依赖它的表不再重建，其余表照做，最终状态 `partial`。不要改构建脚本去"修"它，由主审决定。
   - 结果合并写进 `reports/research/program/data-refresh-2026-10-01/invariance.json`。
6. **新鲜度**：写 `freshness.json`，每张表一项：`last_date_before`、`last_date_after`、`n_new_dates`、`coverage_ratio`、`invariance_pass`、`runtime_s`、实际运行的命令。
   - 日度表的 `last_date_after` 应等于 D。
   - 有正常发布滞后的表写明滞后，例如 FINRA 空头持仓按结算日、Form 4 按申报日。
