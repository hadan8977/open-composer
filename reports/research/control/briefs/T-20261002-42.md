2. **`cancel_open_orders(client, *, account, execution_date=None, plan=None, reason, now)`** and the command `oc book-paper cancel --account A [--date D] --reason TEXT [--all-book]`.
   - **Default**: cancel open orders whose `client_order_id` is in that date's plan file.
   - **`--all-book`**: cancel every open order on the account whose id starts with `bk1-`.
   - **Never touch** other orders. Each account is dedicated to the book, but stay strict anyway.
   - Write a receipt `cancel-<D>-<HHMMSS>.json` next to the orders receipt. It records the reason, the ids it asked to cancel, the broker response per id, and the open orders still left after a re-read.
   - Cancelling is allowed at any time and is not blocked by the kill switch, since it reduces risk.
   - Afterwards it reports any open orders left, for example ones past the cutoff that the exchange no longer accepts cancels for.
3. **`flatten_plan(state, *, account, execution_date, reason, mode)`** and the command `oc book-paper flatten --account A --reason TEXT [--mode close|market] [--confirm-flatten]`.
   - It builds an order list that closes every position: longs sell, shorts buy to cover, whole shares, no $100 minimum.
   - `mode=close` (default): `time_in_force=cls`, inside the existing submission window.
   - `mode=market`: `day` market orders during regular hours only. This is for emergencies.
   - Positions in assets that are not tradable (see the T-40 frozen logic, `asset_lookup`) are listed and skipped.
   - Without `--confirm-flatten`, it prints the plan and writes a dry-run receipt. Nothing is sent.
   - With `--confirm-flatten`, it sends through the same idempotent client-order-id path as `submit_plan`, using the id prefix `bk1-flat-`. Flatten may run while the kill switch is on, because it reduces risk, but the receipt must record the kill-switch state.
   - **Refuse** if any open orders remain: cancel first.
4. **Tests** (at least 10, fake client only):
   - `cancel` default cancels only that plan's ids;
   - `--all-book` cancels only `bk1-*` ids;
   - other orders are untouched;
   - the receipt lists what is left open;
   - `flatten` dry-run sends nothing;
   - the `close` mode builds the right sides and quantities for long, short and SPY/SGOV positions;
   - a frozen name is skipped and listed;
   - `market` mode is refused outside regular hours;
