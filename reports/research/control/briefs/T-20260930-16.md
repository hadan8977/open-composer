### 第 2 步：写 `scripts/run_t20260930_16_overnight_execution.py`

导入方式：

```python
from scripts import run_t20260929_35_overnight_persistence as t35
from scripts import run_t20260930_14_overnight_12m as t14
from scripts import run_t20260930_11_gap_fade_auction as c1
from scripts import run_t20260930_15_quote_check as q15
from scripts import screen_lane as lane
```

脚本分四个阶段，每个阶段写缓存，可断点续跑。

**`sample` 阶段**：

1. 从 t35 面板读 date、symbol、p500、on252、r 五列。每天 t 按 t35 `run_cell_series` 的 LO 分支选前 20 只：`p500` 为真、on252 和 r 有限；当天有效股票少于 40 只就跳过；`np.argsort(on252, kind="stable")` 取最后 20 个。行顺序与面板相同。
2. D1：用 t14 的抽样函数取 20 天，再用 `numpy.random.default_rng(20260930)` 按 T-14 hypotheses 的规则重算核对，两者必须相同，不同就停下汇报。
3. D2：按 hypotheses.md 的"抽样日"抽 20 天（种子 20261001，抽样框升序，去掉 D1 和 6 个提前收盘日）。
4. 写 `cache/sample.json`：每天的 t、t+1 和 20 个代码。

**`official` 阶段**：

1. D1 的（股票, t）先从 t14 的官方价缓存取。缺的，以及 D2 的全部，用 t14 取官方价的同一套调用补取（`c1.fetch_window` + `c1.official_close` / `c1.official_open`）。缓存写到本任务的 `cache/official/`。
2. 用 `q15.fetch_raw_closes` 取 t 和 t+1 的原始收盘价，算 f_d = 本地日线 close_d / 原始 close_d。本地日线 close 从 `data/sip/daily` 读，读法同 t35 或 q15。
3. 记下每个 t 日官方收盘印价的时刻。早于 15:59 ET 的日子按 hypotheses.md 剔除。

**`quotes` 阶段**：

1. 自己写一个 `quotes_at(session, day, hh, mm, ss, symbols)`，支持到秒。
   - 逻辑照 `q15.fetch_last_quotes_batch` 和 `q15.quotes_for`：先取 [T−5 秒, T)，缺的再取 [T−60 秒, T)；复用 `q15.update_last_valid`、`q15.is_valid_quote`、`q15.rfc3339`。
   - 缓存写到本任务的 `cache/quotes/`，不许写进 T-13 的目录。
2. 时刻：t 日 15:55:00、15:59:00；t+1 日 09:25:00、09:30:30、09:31:00、09:35:00（都是 ET）。

**`ledger` 阶段**：

1. 按 hypotheses.md"计算"一节算 P1–P7 的缺口、拆分和开盘/收盘剖面，按"分档"算 `tier_exec` 和 c。
2. 按"阶段 B"算账本：
   - S3 的输入照 `scripts/screen_batch.py` 第 199–206 行：`lane.load_batch_panel(...)`、`shy_ret`、`lane.s3_incumbent(close, leg_open, leg_close, lane.COST_BPS_PRIMARY)`、`rf`。`load_batch_panel` 不接受空候选列表的话，照 screen_batch 的做法最小改动适配，不改 screen_lane。
   - 候选序列：每晚收益记在 t+1 日；K2 前先调 `lane.assert_same_session_convention`。
   - K1、K2、DSR 和诊断 1–5 照 hypotheses.md。
3. 写 `results.json` 和 `report.md`。`tier_exec`、`k1_paper`、`k2_paper`、`k1_auction`、`k2_auction` 由脚本机械算出。
