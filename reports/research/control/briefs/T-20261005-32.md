## Definitions (hypotheses.md section 3; restated)

- Windows: recent 2024-01-08..last session (decision); stress 2017-10-02..2023-08-31; full 2017-10-02..last session.
- Estimation window W(d) = the 126 sessions ending at session d inclusive (returns R). On W: `beta = cov(SMH, SPY)/var(SPY)`, `f = R_SMH - beta * R_SPY`. For a risky weight vector w (SHY and BIL excluded as zero-risk cash): `p = R_W @ w`; `b_m = cov(p, SPY)/var(SPY)`, `b_th = cov(p, f)/var(f)`, `v_e = var(p) - b_m^2 var(SPY) - b_th^2 var(f)`, **`TRS = b_th^2 var(f) / var(p)`** (0 if var(p) = 0). ddof = 1 everywhere. Per-asset loadings `b_th_i` the same way. Skip (no cap, TRS = NaN, counted) while fewer than 126 valid returns exist.
- Levels c in {0.40, 0.30, 0.20, 0.10}. Configuration ids: `ORIG`, `CAP_40/30/20/10`, `H1F_40/...`, `H2F_40/...`, report-only `H1U_40/...`.
- **CAP** (selection-level, before any vol scaling; TRS is scale-free): at each sleeve signal date d, with the target weights w of the row effective at d+1: if TRS(w) > c, move fraction s of every risky holding whose `b_th_i` has the same sign as the sleeve's `b_th` into its substitute: TQQQ, SOXL, TECL -> UPRO; USD -> SSO; every other 1x risky holding (SMH, SOXX, XLK, QQQ, SPMO, GLD, TLT, sector ETFs, SPY itself never moves) -> SPY. s = smallest value on the grid 0, 0.01, ..., 1.00 with TRS(w(s)) <= c; if none, s = 1 and flag the date. The capped row is held until the next change. Then run the sleeve's own frozen engine on the capped weights: S3 `gross = salvage.simulate(w_cap, legs, ones, 0)` -> `scale = salvage.vol_scale(index, sig_dates, gross, tranche.S3_TARGET, boost, tranche.S3_BOOST_TARGET)` -> `eff = tranche.effective_weights(w_cap, scale)` -> `tranche.simulate_effective(eff, cols, legs, cost)`; S2 the same with `combo.S2_TARGET` and no boost; S1 no vol scaling (`scale = ones`); C2 `salvage.simulate(w_cap, legs, ones, cost)`. Add any substitute column (SSO, UPRO, SPY) the weights frame lacks, filled with 0.
- **H1F** (margin account; on the sleeve's effective weights after its vol scale): hedge update sessions e = sessions where the effective weight row differs from the previous row; use W(e-1). `Q = c/(1-c) * (b_m^2 var(SPY) + v_e)/var(f)`; if `|b_th| > sqrt(Q)`: `h = b_th - sign(b_th) * sqrt(Q)`, else h = 0. Overlay from the open of e, held constant: SMH weight `-h`, SPY weight `+h*beta`; SHY reduced by `min(SHY, h*beta)`; debit `D = max(0, h*beta - SHY_before)` charged `D * 0.065/252` per session. Short proceeds earn nothing and do not offset the debit (conservative). Feasibility on each update session (pilot: on the combined account 0.642 S3 + 0.358 C2; single sleeves: on themselves), NAV = 1: initial `0.5 * (long MV + short MV) <= 1`; maintenance `0.30*long_1x + 0.50*long_2x + 0.75*long_3x + 0.30*short <= 0.9` (2x: USD, SSO; 3x: TQQQ, SOXL, TECL, UPRO, SOXS). If infeasible, scale every hedge overlay in the account by one common lambda in [0, 1] (bisection to 1e-4) to the largest feasible value; record lambda and the achieved TRS. **H1U** = same with lambda = 1 always (report-only).
- **H2F** (cash account): same h; overlay n SOXS + u UPRO with W(e-1) loadings solving `n*b_th_SOXS + u*b_th_UPRO = -h` and `n*b_m_SOXS + u*b_m_UPRO = 0` (n, u >= 0; if the solve gives a negative value, set the overlay to 0 for that session and count it). Funded only from that sleeve's SHY: if `n + u > SHY`, scale both by `SHY/(n+u)`. SHY reduced by n + u; no debit. Achieved TRS = TRS of (risky weights + overlay) on W(e-1).
- Overlays are appended as extra columns to the effective weight matrix and run through `tranche.simulate_effective` (turnover cost applies to every column including SHY changes, exactly as the engine does); for C2/S1 build the effective matrix from the weights frame (scale 1) and do the same. Debit cost is subtracted afterwards.
- Costs: main 10 bp per side; 2x check 20 bp per side plus 100 bp/yr on short notional (`|short| * 0.01/252` per session), same weight paths.
- S3 is evaluated at offsets 0, 4, 8, 12, 16 (`tranche.s3_weights(close, o)`); the S3 series used everywhere is the equal-weight mean of the 5 offsets' daily net returns. CAP is also run at all 21 offsets (report-only distribution of the pilot's recent ΔSR). C2: offset 0 only. S1, S2: offset 0, CAP and ORIG only.
- Pilot O1 = `0.642*S3 + 0.358*C2` (plan v2 D7.1; no cash leg, no borrowing), daily fixed weights, built from each configuration's sleeve series (H1F feasibility is the account-level lambda above).
- Excess `x = r - rf`. Per window: `k = sd(r_ORIG)/sd(r_cfg)`; same-vol excess `k*x - max(k-1, 0)*(0.065/252 - rf)`; Sharpe `mean/sd*sqrt(252)`; **ΔSR = SR(cfg, same-vol) - SR(ORIG)**; also the raw Sharpe. ES97.5 = mean of the same-vol daily excess returns at or below their 2.5% quantile. Max drawdown on raw and same-vol cumulative returns. ρ = correlation of daily r_cfg and r_ORIG.
- Replays (frozen in build.json **before** any configuration is evaluated, from SMH closes only): R1 peak = argmax SMH close on 2024-06-01..2024-07-31, trough = argmin after the peak through 2024-08-31; R2 peak 2025-01-01..2025-03-31, trough through 2025-04-30; R3 peak 2026-06-01..2026-07-31, trough through 2026-08-31. Per configuration: same-vol (recent-window k) cumulative return from the peak close to the trough close, and the max drawdown inside.
- Bootstrap: paired stationary block bootstrap of the O1 recent same-vol daily series (cfg and ORIG resampled with the same indices), mean block 21, 2000 draws, `numpy.random.default_rng(20261005)`; report the 10/90 and 2.5/97.5 percentiles of ΔSR.
- Theme P&L share (Q4), ORIG of S3, C2, S1, S2, O1: for each session t, `b_th(t)` from W(t-1) at the effective risky weights of t, times `f_t = R_SMH,t - beta(t-1) R_SPY,t`; sum over the recent window divided by the sum of the sleeve's gross daily returns there; the same for `b_m * R_SPY`.
- Daily monitoring (O1 decision configurations and ORIG): ex-ante TRS each session from W(t-1) at that session's effective weights (incl. overlays): mean before/after, and the share of sessions with TRS > c + 0.05.
- Placebos (report-only): replace SMH by each of XLE, XLF, XLV, XLI, XLY, XLP, XLU, XLB as the theme asset (same definitions; the H1U hedge shorts that ETF and buys beta SPY); CAP and H1U at the 4 levels; objects O1, S3 (5-offset blend), C2. Report bind rate, recent ΔSR, stress ΔES (relative), mean replay change. `semis_specific[object][c] = ΔSR_semis(c) - median_j ΔSR_j(c)` (CAP and H1U separately).

## Decision (hypotheses.md section 5; code writes it, no judgement)

For v in {CAP, H2F, H1F} and c in {0.40, 0.30, 0.20, 0.10}, on O1, recent window, main costs:
- `cost_ok`: ΔSR_recent >= -0.10;
- `benefit`: mean over R1-R3 of (cfg replay return - ORIG replay return) >= +0.010, OR stress `|ES97.5_cfg| <= 0.95 * |ES97.5_ORIG|`;
- `monotone`: `cost_ok` holds at c and at every looser level of the same version;
- selected(v) = the tightest c with all three; else none.
- `pilot_limit` = selected(CAP) if any, else selected(H2F), else selected(H1F); if a hedge version's selected level is strictly tighter than CAP's, record both under `pilot_limit_alternatives`.
- `mechanical_status`: `identity_failed` | `pilot_limit_selected` | `cost_ok_no_benefit_monitor_only` (some cost_ok level exists but none has benefit) | `no_level_within_cost` (no version is cost_ok at 0.40).
