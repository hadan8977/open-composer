## Why

Both contracts failed mechanically. See:
- `reports/research/iterations/t20261001_book_v1/decision-record.md`
- `reports/research/iterations/t20261001_book_rf1/decision-record.md` (its numbers are in `results.json` and `report.md` in the same directory)

The signal layer works: M0 composite long-short, industry-demeaned, daily, open to open. Its gross Sharpe is 1.68 in window A (2024-01-08..2026-06-30) and 3.06 in window B (2026-07-01..09-17). The portfolio built from it does not: M0_A, close fill, has gross 1.10 in A and −0.80 in B.

Facts the lead extracted from the T-08 cache:
- **Style caps bind.** Share of rebalances with the style exposure at its cap, median over offsets:
  - M0_A: investment 85%, momentum 45%, size 40% (cap 0.10), value 37%, resid_vol 31%;
  - M1_C: resid_vol 91%, size 89%.
  Five of the nine themes are risk-model styles (value, profitability, investment, momentum, low risk).
- **Close fills cost more than they save.** M0_A anchor: close gross 0.876, net 0.616; open gross 1.155, net 0.847. This holds even with the open half-spread modelled at 4.1× the close.
- **Costs.** 172 bp/yr in the anchor window: spread 118, impact 31, fees 10, borrow 13.

The next contract (v1.1) must rest on measured causes. This task measures them.

## Part 1 — preregistration, before any new number
Write and commit `reports/research/iterations/t20261001_book_v1/postmortem/prereg.md` before running anything. Run `date -u` in the same command that writes it. It must contain:

**Configs.** All use variants M0_A and M1_C, offsets 0–4.
- **L0**: v1 as run (T-08 close paths; reuse them).
- **L1**: L0 with `style_cap=None`.
  - `OptConfig.style_cap` is a single scalar, so this uncaps every non-size style.
  - Size keeps its 0.10 cap. Market beta keeps `beta_cap` 0.02. Industry stays 0.01, name 1%, ex-ante vol 5%, gross 1.0.
  - Costs and everything else are unchanged.
- **L2c**: L1 with open fills and the cost model's open snapshot. This is the conservative case, the same mechanics as T-08's `*_open` paths.
- **L2a**: L1 with open fills but close-snapshot costs. This is the optimistic bound for an opening-auction fill.
  - `book_config` derives realised costs from `make_cost_fn(snapshot_for(exec_price))`, so build the config with `exec_price="open"` and then `dataclasses.replace(cfg, cost_fn=make_cost_fn(snapshot_for("close")))`.
  - Also set `OptConfig(snapshot="close")`.
  - If this is impossible without editing a bound file, drop L2a and say so.

**Windows** (as RF1): A, B, stress, anchor. Net Sharpe is min(plain, cash-aligned) per offset, then the median. Gross Sharpe is also reported.

**Decision rules.** Write them before the runs; they are evaluated mechanically.
- **D1, style alignment.** L1 minus L0 median A-window gross Sharpe is ≥ +0.30 for both variants, and the stress-window gross change is ≥ −0.30 for both. If true, v1.1 replaces the caps on alpha-aligned styles with a risk budget.
- **D2, execution.** L2c minus L1 net is ≥ +0.15 in A and ≥ 0 in stress, for both variants. If true, v1.1 executes in the opening auction. If only L2a clears it, opening-auction costs must be measured on paper first.
- **D3, costs.** If L1's cost drag (gross minus net Sharpe, A window) exceeds 0.30, record "v1.1 needs a slower rebalance or a stronger cost penalty" as a candidate change, not a decision.

**Trial accounting.** Three configs × two variants is six new trials, bringing the program total to 89 for any future DSR.

3. **Transfer coefficient**, for L0 and L1, at every rebalance:
   - Rebuild the alpha used at that rebalance with the same `AlphaSource` call.

   - Also report the risk-adjusted form from Clarke et al. (2002), if the source defines it unambiguously.
   - Give the median per window.
4. **P&L attribution**, for L0 and L1, offset-blended:
   - Split the daily stock-book return into market, industry, each style, and specific, using the risk model's exposures and daily factor returns under `data/research/equity_book/risk/`. Use the exposure date ≤ t, never later.
   - Report each component's annualised contribution and Sharpe in A, B and stress.
   - Report the ETF-hedge leg separately.
   - This answers where the book's P&L actually comes from.
