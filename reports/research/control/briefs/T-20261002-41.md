# T-20261002-41 brief: post-close prices file for reconciliation (official close + 15:45 snapshot), from the local SIP archives

Written 2026-10-02 07:36 UTC by the interactive lead (Opus).

## Why
`oc book-paper reconcile` (`open_composer/book_paper/cli.py`, the `reconcile` command) needs `--prices-file`, a JSON file of the form `{"official_close": {sym: px}, "snapshot_1545": {sym: px}}`. `post_close.py` uses the two maps for reconciliation, TCA (slippage vs the official close and vs the 15:45 snapshot), shadow costs and realized exposures. Nothing builds this file yet (T-20261002-28 report). Without it, the first paper order day of book v1.2 has no fill-quality or shadow-cost record. That record is a paper-start requirement.

Both prices are available locally after the evening refresh, so **no network call is needed**:
- The 22:00 UTC weekday cron runs `scripts/update_sip_archive.py --kind minute`, which refreshes the minute archive under `data/sip/minute/`.
- `data/sip/daily` holds the daily bars.
- The snapshot is only used after the trade (TCA), so it does not have to be real time.
