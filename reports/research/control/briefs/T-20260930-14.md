```python
from scripts import run_t20260929_35_overnight_persistence as t35

```

不许修改 t35 的脚本或缓存。脚本分三个阶段：

**`band` 阶段（测试 A）**：

1. 复用 t35 的 `find_candidate_symbols`、`load_wide_float32`、`rank_desc`、`overnight_intraday_returns`、`rolling_signals`、`next_night_return`、`next_day_intraday_return`。
2. 候选改为"曾经进过 dv21 前 3200 名"的代码。
3. 池 B = 当日 dv21 排名 1501–3000，其余过滤与 t35 相同。
4. 只算 ON252。
5. 用 `decile_long_short` 算每晚的 LS；统计用 `newey_west_t`、`series_stats`、`window_block`；安慰剂用 `placebo_series`，100 个种子；另出按年表和下一天日内收益。
6. 缓存到本任务的 `cache/band_panel.parquet`。

**`official` 阶段（测试 B）**：

1. 用 `numpy.random.default_rng(20260930)` 从主窗（2024-01-08 → 2026-09-29）的面板交易日中无放回抽 20 天。
2. 每天从 t35 面板取 ON252_P500 的多头十分位、空头十分位和 LO 前 20。十分位的切法与 t35 的 `decile_long_short` 一致。
3. 对每个（股票, t）：
   - 用 `c1.fetch_window` 取 t 日收盘前后和 t+1 日开盘前后的逐笔成交；
   - 用 `c1.official_close`、`c1.official_open` 取官方价；
   - r_官方 = 官方开_{t+1} / 官方收_t − 1，与面板里的 r 配对。
   - **口径对齐（主审 2026-09-30 12:30 补充，属于测量规则，不改门槛）**：
     - 本地日线是复权价（拆股和分红都复权过），逐笔成交是原始价。
     - 先用 `GET /v2/stocks/bars?timeframe=1Day&adjustment=raw` 取 t 和 t+1 的原始收盘价 raw_d。
     - 算每天的复权因子 f_d = 本地日线 close_d / raw_d。
     - r_官方 = (官方开_{t+1} × f_{t+1}) / (官方收_t × f_t) − 1。
     - 不做这一步，除权除息夜和拆股夜会把分红和拆股比例误算成 Δ。
     - 做法照 T-20260930-15 的 `scripts/run_t20260930_15_quote_check.py`，那里的报价就是这样换到复权口径的。
     - 另报：f_{t+1}/f_t ≠ 1 的夜数。
4. 按 hypotheses.md 的"门槛 B"算 Δ。报告取不到官方价的比例。
5. 缓存每个（股票, t）的取数结果，断点续跑。

**`diag` 阶段**：

1. 在 t35 面板上算 hypotheses.md 的诊断 1–6，只针对 ON252 的 P500 和 P1500。
2. 12-1 动量需要收盘价：从日线两个根按 t35 同样的清洗规则读，或者由 t35 面板里已有的收益推出。二选一，在报告里写明用的是哪种。
3. 合并三个阶段的结果，写 `results.json` 和 `report.md`，由脚本机械算出 `gate_a`、`gate_b`（true/false）。
