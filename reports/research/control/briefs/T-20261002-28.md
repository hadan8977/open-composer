## Steps
1. **Generator** `open_composer/book_paper/v12_targets.py`:
   `build_v12_targets(decision_date, *, variant, data_root=None) -> dict[str, BookTarget]`
   - Returns `{"quant1": F1, "quant2": F2}`, schema 2.
   - It is stateless: for each of the 5 tranches it recomputes the weights at that tranche's last decision date ≤ D, sizes the virtual shares at that date's `P_ref`, and drifts them by fixed shares to D. This is exactly the T-26 account simulator's state at D.
   - **Account target weights** = Σ_o virtual shares × close(D) / E, with `reference_prices` = close(D). The engine's `round_half_away(weight × E / price)` therefore reproduces `round_half_away(Σ virtual shares)`.
   - **SPY** = the tranches' virtual hedge shares (F1). For F2, add core 1.0 × E at close(D).
   - **F1 SGOV leg:** `x = max(0, min(G − L − S, 1 − L + S))` from the target L and S. Price it with SGOV's close(D); if SGOV is missing, use BIL and state it in `book_id`.
   - **exposures:** per name, from the data root at D:
     - beta = the EWMA beta that the hedge used;
     - industry = `ind_code`;
     - size;
     - `dollar_adv_21`, `vol_21`.
   - **book_id:** `t20261002_book_v12:<variant>:<F1|F2>`.
   - `data_root` defaults to the research snapshot. Live runs set `OC_EQUITY_BOOK_DIR=data/live/equity_book`. If T-22's directory override is not merged yet, accept an explicit path argument and say so.
   - `variant` must be one of the 4 contract variants. The CLI takes it from `reports/research/iterations/t20261002_book_v12/results.json` → primary variant. It refuses if the file or its decision is missing, or if the decision is not a paper start.
2. **CLI** `oc book-paper targets --decision-date D [--variant V] [--data-root P] [--write]`.
   - Without `--write`, it prints a summary only: names, L, S, hedge, SGOV, gross, beta, max name weight.
   - With `--write`, it writes both target files through `write_target_file`. `logged_at_utc` comes from `date -u` at writing.
   - It refuses if the data root's last session is earlier than D.
   - It makes no broker calls.
3. **Parity test** (`tests/test_book_v12_targets.py`, plus one slow test marked `slow` if needed):
   - for 3 historical decision dates in the recent window (one with VIX > 20.60), the generator's target shares (`round_half_away(w × E / P)`) equal the T-26 account simulator's target shares for both forms;
   - SPY and SGOV match within one share;
   - payload hashes are stable across two calls.
4. **Historical engine replay** (`scripts/book_v12_engine_replay.py`): for the last 60 sessions of the research snapshot and the primary variant, both accounts:
   - feed the generator's target and a fake `AccountState` (the previous day's simulated holdings and equity) into `build_plan` (`as_of` = the execution date, `now` = 14:00 ET);
   - count the days on which each check fails, and the orders per day;
   - write `reports/research/iterations/t20261002_book_v12/engine-replay.json`.
   - Every failing check must be explained: either a real contract issue (tell the lead) or a replay artefact (fix the replay).
   - The point is that no check should block a normal day. Do not loosen any limit to get there. Report and let the lead decide.
5. **Daily driver** (`scripts/run_book_v12_daily.py`):
   - it writes targets for decision date D after the live refresh;
   - `--plan` builds the dry-run plans the next session;
   - `--submit` is **never** used by this task and must refuse unless the env var `OC_BOOK_V12_SUBMIT=1` is set, which only the owner-approved cron will do;
   - it takes a lock file and logs to `logs/book_v12_daily.log`;
   - exit codes: 2 = data not fresh, 3 = targets refused.
   - In the report, give the proposed crontab lines (UTC):
     - targets after the 22:45 live refresh;
     - plan and submit 18:30–19:30 UTC (14:30–15:30 ET) on the execution date;
     - reconcile after 21:30 UTC.

   Do not install them.
6. **Finish:**
   - Run ruff format/check, then `uv run pytest -q tests/test_book_v12_targets.py tests/test_book_v12.py tests/test_book_paper.py tests/test_book_paper_hedge.py`; all must pass.
