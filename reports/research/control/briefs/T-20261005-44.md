   - **F2 时点**（不设通过线，但必须写出规则）：只保留交易日的行；报告节假日行与前一交易日完全相同的比例。在 2024-10-01..2026-09-15 每个日期，hv_current 与自算历史波动率（窗口 w ∈ {10, 20, 21, 22, 30} 的日对数收益标准差，截至 d 收盘 = H_same，截至前一交易日收盘 = H_prev）的截面 Spearman（≥ 200 只），取各日期中位数，输出 10 个数的表。H_prev 最佳中位数比 H_same 最佳中位数高 ≥ 0.01 → `as_of_rule = "previous_session"`，否则 `"same_day"`。公布时点：一次 API 查询 `SELECT date, message FROM dolt_log LIMIT 100`，从 message "volatility_history YYYY-MM-DD update" 取数据日期，算提交时刻是否早于"按 as_of_rule 得到的 t 之后第一个交易日的美东 15:50"，比例 ≥ 0.95 → `publication_shift_sessions = 0`，否则取延迟的 95 分位（交易日，至少 1）。
