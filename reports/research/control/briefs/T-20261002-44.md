### 2. Data build (no outcome data touched)

**`scripts/fetch_kalshi_macro.py`**

- **Endpoints:** public, no key. Base `https://api.elections.kalshi.com/trade-api/v2`.
  - `/series/{s}`, `/events?series_ticker=…&with_nested_markets=true` (paginate by cursor);
  - `/historical/cutoff`;
  - `/historical/markets/{ticker}/candlesticks`;
  - `/series/{s}/markets/{ticker}/candlesticks`.
- **Request discipline:**
  - Route each request by the cutoff, as the Kalshi docs and the `WillBtK/macro_kalshi` repo do.
  - At most 5 requests per second; back off exponentially on 429/5xx.
  - Checkpoint after every event so the run can resume.
- **Series:**
  - Required: `KXCPI` (headline MoM; older `CPI-*` events come back under the same series), `KXPAYROLLS` (older `PROLLS-*`), `KXGDP`, `KXFED`.
  - Optional: `KXPCE` if it exists, `KXCPICOREYOY` (diagnostic only), `KXU3` (diagnostic only).
  - Record which exist and how many events each has.
- **Candles:** hourly (`period_interval=60`) for every market of every event, from the market's open_time to its close_time. Keep `end_period_ts`, yes_bid/yes_ask OHLC, price OHLC, volume and open_interest.
- **Raw store:** `data/research/prediction_markets/kalshi/raw/` (parquet, one file per event). Add the directory to `.gitignore` if it is not already ignored; add that one line only.

**`scripts/build_kalshi_release_uncertainty.py`**

- Builds one row per (series, event) with: release date T (US/Eastern date of the market close_time; 08:25 ET for data releases; for FOMC, record the decision day and verify against the event title), the signal timestamp (last hourly candle ending at or before 15:00 ET on T-1, the previous NYSE session), the number of usable strikes, the cleaned implied pmf mean, U (std), U_rel, and the warm-up and exclusion flags.
- Everything is as defined in hypotheses.md:
  - mid when the spread is at most 0.10, else the last price in that candle;
  - middle-out monotone cleaning;
  - difference into a pmf on bin midpoints;
  - U_rel against the median of the previous 12 events of the same series;
  - warm-up below 6 prior events;
  - excluded below 4 usable strikes.
- **Middle-out cleaning:** port it from `WillBtK/macro_kalshi` (MIT). Clone it into `/tmp/T-20261002-44/`, credit it in the docstring, and keep the copied code small.
- **Output:** `data/research/prediction_markets/kalshi/release_uncertainty.parquet`.
- **Tests** in `tests/test_kalshi_release_uncertainty.py`, on synthetic candles only:
  - cleaning keeps the CDF monotone;
  - pmf sums to 1;
  - std is right on a known two-point distribution;
  - the signal-candle choice never uses a candle ending after 15:00 ET on T-1;
  - U_rel uses only prior events;
  - day-level dedupe takes the max U_rel.
