## Step 2: module `open_composer/research/regime/jump_model.py` (plus `__init__.py`)

Implement exactly the contract's section 3 definitions:

- `ewm_downside_dev(r, hl)` = `sqrt(r.clip(upper=0).pow(2).ewm(halflife=hl).mean())`.
- `ewm_sortino(r, hl)` = `r.ewm(halflife=hl).mean() / ewm_downside_dev(r, hl)`.
- `features(market_df, spec)`: F3 is DD(10), Sortino(20), Sortino(60); F4 adds the EWM(hl 10) of log VIX; F6 adds log(VIX/100) − log(RV21), with RV21 = sqrt(252 × rolling 21-session mean of excess²), and the 21-session difference of BAA10Y.
- `fit_jump_model(X, lam, n_init=10, seed=0, max_iter=1000, tol=1e-8)`:
  - loss = 0.5 × squared Euclidean distance;
  - k-means++ starts via `sklearn.cluster.kmeans_plusplus` with seeds `seed + i`;
  - alternate a full DP with backtracking for the states and the means of assigned rows for the centres; keep the previous centre if a state is empty;
  - stop when the objective improves by less than tol or the states repeat;
  - return the best start (centres, in-sample states, objective).
- `online_states(X, centers, lam)`: forward pass only, `values[t] = loss[t] + min_j(values[t-1][j] + lam * (j != k))`, state = argmin of `values[t]` (no backtracking).
- `order_by_cumret(centers, states, excess)`: relabel so state 0 = higher cumulative excess return in the training window (bull).
- `fit_hmm_diag(X, n_init=10, seed=0, max_iter=200, tol=1e-6)`: 2-state diagonal Gaussian HMM, Baum–Welch with scaling. `hmm_filtered(X, params)`: forward filter only.
- GMM: `sklearn.mixture.GaussianMixture(n_components=2, covariance_type="diag", n_init=10, random_state=seed)`.
- `rolling_states(feat, excess, model, value, train=3000, lookback=3000)`:
  - refit on the first session of each January and July once 3000 complete feature rows exist;
  - clip each feature at training mean ± 3 sd, then z-score with the training mean and sd;
  - after each refit run the online pass from 3000 sessions before the refit date to the next refit;
  - return the daily bull indicator. It may use only data up to each date.
- `cv_select(seqs, excess, rf, val=2016, cost_bps=10)`:
  - at the first session of each month, for each candidate value, compute the Sharpe over the trailing `val` sessions of the 0/1 strategy built from that value's own sequence (multiplier decided at close d, effective d+2, 10 bp per change);
  - pick the maximum (ties → the larger value);
  - the choice applies from session t+2; return the combined multiplier and the choices.
  - For H2 the candidates are the smoothing k ∈ {0, 2, 4, 8, 20}: bear if the trailing-k mean of the raw online bear indicator > 0.5.

## Step 5: driver `scripts/p2_s2_regime_layer.py --stage index`

1. For each of the nine specs, build the daily multiplier decided at each close: JM/H2/G2 via `rolling_states` (+ `cv_select` for the CV specs); TV per the manifest (VIX terciles over 1990-01-02..2015-12-31). Save `cache/multipliers.parquet` (index = session date, columns = candidate ids, value = multiplier decided at that close; NaN before a spec's first test month) and `cache/cv_choices.parquet`. Record the sha256 of multipliers.parquet in `index_results.json`.
2. **Index-level 0/1 strategy.** Day-t return = m[t−2] × excess[t] + rf[t] − 0.001 × |m[t−2] − m[t−3]|.
   - Exposure-matched volatility target: m_VT[t] = min(1, τ / σ̂[t−2]), with σ̂ = EWM(halflife 21) of excess, annualized with √252. Pick τ by bisection so that the window mean of m_VT equals the window mean of m[t−2]; charge the same cost on |Δm_VT|.
   - Buy-and-hold: m ≡ 1.
3. **Windows:**
   - reproduction 1990-01-02..2023-12-29 for J3_CV, J3_L15, J3_L50, J3_L150, H2_CV and G2;
   - all nine specs on 2010-01-04..2026-07-31;
   - also stress 2017-10-02..2023-08-31 and recent 2024-01-08..2026-07-31 at index level, report-only.
4. **Metrics per series:**
   - Sharpe of excess (mean/sd × √252), CAGR including rf, volatility, MDD of the compounded total return, Calmar (annual excess / |MDD|);
   - ES5% (mean of the worst 5% daily returns), turnover (Σ|Δm| per year), mean exposure, changes per year;
   - Sharpe difference spec − VT and spec − B&H, each with a paired stationary bootstrap 95% interval (mean block 21, 2000 draws, seed 20261006).
5. **Reproduction gate** (contract section 4), mechanical, on J3_CV 1990–2023:
   - R1: Sharpe − B&H ≥ +0.10;
   - R2: MDD better by ≥ 15 percentage points;
   - R3: ≤ 2 changes per year;
