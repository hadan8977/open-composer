# T-20260928-30 小盘/低流动性 LightGBM 价量排序模型多做空头寸成本压测

承接 `dir:lgbm_price_volume_ranking_small_caps`（`reports/research/iterations/t20260928_10_ml_killtest/report.md` 第二次运行）：冻结 B0 模型（24 个价量特征、月度形成、21 日 beta 调整超额收益、3 年滚动训练、季度重训、embargo 21），逐日预测（用覆盖当日的那一折模型），在拓宽后的股票池（收盘价>=$3、21 日美元 ADV>=$100 万）上构建两个只做多组合，计入逐只股票的 Abdi-Ranaldo (2017) 价差成本、容量上限和调仓缓冲带。

## 规格（预注册，未在看到结果后调整）

- V1：全池预测值前 50；V2：仅在最不流动三分位内取预测值前 50。等权，调仓缓冲：原持仓排名 <=150（V1 全池 / V2 三分位内）才保留，
  否则用当日最佳未持有名字补满 50。
- 21 个月度调仓日偏移（`tranche.shifted_signal_dates`），收盘出信号、次日开盘成交。
- 每只股票每边成本：基准 = 10bp + 0.5 x 价差；压力 = 20bp + 1.0 x 价差；
  价差 = Abdi-Ranaldo (2017) 收盘-最高-最低价估计量，21 日滚动，点时，下限 0、上限 5%。
  另报固定 10bp / 20bp 作参照。
- 容量：账户 $100,000，单只持仓 <= 该股 21 日成交额中位数的 1%；
  超出部分留作闲置现金（不投资、不计收益）。

Modal 实测花费（`logs/modal-t20260928-30-*.log`，`actual_cost_usd`）：
两次 smoke（$0.0125 + $0.0132）+ 一次修复前正式跑（$0.3566，含一个逐日成本 bug，见下）+

修复说明：第一次正式跑里，`simulate_book` 对"该股当天有价差记录但估计值本身是 NaN"（trailing
21 日窗口不足，如次新股）处理有误——只有当整只股票在当天的流动性表里完全缺行时才会回退到
0 价差；如果行存在但 `spread_21` 是 NaN，会把 NaN 直接乘进当天的成本，导致那一天全部持仓的
净收益变成 NaN 并被 `metrics` 的 `dropna()` 整天剔除（而不是该股当天不计价差成本、其余照算）。
换手极低的调仓日恰好是这些 NaN 最集中的日子，导致换手和价差成本被系统性低估。修复为统一走
`per_stock_cost_bps`（已单测），NaN 价差按 0 处理但当天其余持仓和收益正常计入。本文件的数字
来自修复后的第二次正式跑（`logs/modal-t20260928-30-real2.log`）。
