# t20261002_lazy_prices_ic：10-K 文本变化（Lazy Prices）的残差 IC 入库检验 — 预注册

写于 2026-10-02 01:37 UTC（01:07 主审轮，Opus），早于任何相似度数据。数据由 T-20261002-03 建，检验由 T-20261002-04 跑。本文件冻结后不改；要改只能写带日期的修正案，而且必须早于读到任何相似度值。

## 1. 为什么做

- 组合 v1 的预注册停止条件 10-01 19:25 成立：M0 在对标窗的残差 IC 太弱，t 值 U3000 1.16、P1000 0.91。按停止条件先补信号，再开 v2。见 `t20261001_book_v1/residual-ic-summary.json`。
- 机主的信号分级把文本、公告排在量价之上。
- 这个信号一年只更新一次，换手极低，正好补 v1 的短处：v1 每年被成本拖掉 172 bp。
- 证据见 `direction-review.json`。原文 1995–2014 年价值加权多空每月 34–58 bp（t 3.59）。2015 年以后没有大宇宙的公开复现；超大盘股上两份近期结果都是零。所以先验是"弱到中等"：真正缺的就是我们自己宇宙里的这次测量。

## 2. 数据（T-20261002-03）

- **申报**：
  - 表格只取 `10-K`，不含 10-K/A、10-KT、10-K405。
  - 范围：申报日 2014-07-01..2026-09-30，CIK 属于研究面板 2016–2026 年任一时点 U3000 成员。symbol→CIK 用 `data/features/sic_map/sic_map.parquet`，覆盖该日期的链接里取跨度最长的一条，跨度短于 180 天的链接不用。
- **可见时间**：
  - `acceptanceDateTime` 来自 `data/raw/sec_submissions/submissions.zip`，作为 visible_at。
  - 用 `scripts/build_h20260928_16_sentiment_accel_feature.py` 的 `attribute_trading_day` 映射到交易日 V：V 是第一个 16:00 ET 收盘时刻不早于 visible_at 的交易日。
- **文本**：
  - 主文档 HTML 用 lxml 转成文本，去掉 `ix:header` 和隐藏元素，再去掉全部 `<table>`。
  - 分节：全文；Item 1A 风险因素，止于 Item 1B 或 Item 2；Item 7 MD&A，止于 Item 7A 或 Item 8。
  - 目录里会重复出现条目标题，同名条目取后面正文最长的那一处。
- **分词**：转小写，取 2–20 个字母的词，不做词干化，不去停用词。
- **配对**：同一 CIK 的当前 10-K 和上一份 10-K，申报间隔 300–430 天；不在这个区间就不配对。
- **相似度**，三节各算两种：
  - `cos`：原始词频向量的余弦；
  - `jac`：词集合的 Jaccard。
  - 某一节少于 50 个词，记为缺失。小报告公司常写"本项不适用"，所以不会填零。

## 3. 候选（共 3 个，全部计入试验数）

| 编号 | 信号 | 方向 |
|---|---|---|
| LP_FULL | 全文 `cos` | 越高越好（"没改写"的跑赢） |
| LP_RF | Item 1A `cos` | 同上 |
| LP_MDA | Item 7 `cos` | 同上 |

- `jac` 只作稳健性报告，不进判定。
- 方向事先固定为正，不看数据再选方向。按 Quantpedia/Brain 的结果，正面措辞的方向会反过来；所以方向必须预先写死，不能看了数据再定。

## 4. 测量（T-20261002-04，简报由下一主审轮写，写的时候不许读任何相似度值）

- **形成日**：和 `t20261001_book_v1/formation_ic.parquet` 完全相同。目标收益就是那里九个主题用的"因子中性 21 日远期开盘收益"，同一个研究快照，不重算风险模型。
- **截面**：
  - 形成日 F 的 U3000 成员里，取最近一份满足 V < F（严格早于）、配对年龄 ≤ 15 个月的 10-K 配对；
  - 没有配对的不进截面，不插补；
  - 每个形成日的有效股票数 < 300 时，该日不计。
- **统计**：
  - 每个形成日的 Spearman 秩 IC，按窗口取均值；
  - t 值用 Newey-West，滞后 3 期；
  - 同时报年化 IR = 均值 / 标准差 × √12。
- **窗口**：
  - 对标窗：形成日 2024-01..2026-08，**用来判定**；
  - 压力窗：2017-10..2023-08，只看符号（近期市场规则）；
  - P1000 另报，不进判定。
- **安慰剂**：
  - 在每个"可见月份"（V 所在的日历月）内，把相似度在不同公司之间随机置换，100 个种子；
  - 真实的对标窗 IC 均值要高于安慰剂的 95 分位。
- **独立性**：在形成日计算候选和 M1 合成分的截面秩相关，取全部形成日的中位数。

## 5. 判定（冻结）

- **PASS**，进信号库作为候选主题"文本变化"：至少一个候选同时满足下面四条；几个都过，取对标窗 t 最大的一个，这次选择也计入试验数。
  1. 对标窗 IC 均值 > 0，Newey-West t ≥ 2.39（3 个候选的 Bonferroni，双侧 5%）；
  2. 压力窗 IC 均值 > 0；
  3. 对标窗 IC 高于安慰剂 95 分位；
  4. 和 M1 的秩相关中位数 < 0.5。
- **WATCH**：最好的候选对标窗 t 在 [1.5, 2.39)、方向为正，压力窗 t ≥ 2，安慰剂也通过。唯一的下一步是加 10-Q（同季度对上年同季度，原文的另一半，样本是现在的三倍）。10-Q 的预注册要在任何 10-Q 数据之前写，试验数再加 3。
- **FAIL**，关闭这个方向，死因记为"我们的宇宙里发表后衰减"：其余情况。包括三个候选的对标窗 t 都 < 1.5 或方向为负；或者最好的候选没过安慰剂。
- **说明**：
  - 对标窗只有约 32 个形成日，信号又一年只变一次，统计效力有限。所以设了 WATCH 档，而不是用短窗口一票否决（评判标准 v2：短窗口不单独否决）。
  - 但 WATCH 只允许加 10-Q，不允许换方向、换分节或加别的度量。

## 6. 过了之后做什么

- PASS 后，在 v1.1 或 v2 合同里预注册"加入这个主题后组合净夏普的变化"，两个窗口都要看，同时做安慰剂。纲领"新信号的入口"一节要求的入库判法，由组合层来完成。
- 再往后才考虑：用 LLM 给风险因素的变化分类（DeepSeek 端点，增量打分，不用 Claude 批量打分），以及嵌入向量和同行传导（arXiv 2606.29290 一类）。这些都不在本次检验里。

## 7. 预算和试验数

- 数据管道最多两个执行轮；检验一个执行轮；不花 Modal。
- 本档案试验数为 3。WATCH 后加 10-Q 再加 3。组合层的试验数另算，进组合合同的 DSR。
