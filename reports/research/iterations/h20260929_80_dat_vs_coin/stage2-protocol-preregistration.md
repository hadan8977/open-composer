# Stage 2 protocol (written after the stage-1 IC gate continued, before any book return was computed)

Stage-1 status when this was written: results.json gate_checks continue = true via cell P3_Z120 only (results-run1-padding-bug.json is a superseded first run in which a flat-zero pre-listing history inflated P3 z-scores; P3_Z250 passed only in that buggy run). Candidate list (24) and thresholds are unchanged from candidate-manifest.json.

Script: scripts/run_h20260929_80_dat_screen.py (sha256 at preregistration: 2779f10b21879b01f1a082a3282a4ebeca2fe64418ae430ab31bfc35f5c1a6ff). scripts/screen_lane.py cannot hold shorts, so the frozen lane / T-37 pieces are reused unedited (S3 incumbent, K2 diversifier edge, tier_from, signed simulator, DSR).

- Books: weekly signal dates, 5 offsets (median offset judged). Signal at the close, effective at the next open. State -1 = short DAT / long coin, +1 = long DAT / short coin. Z: enter at |z| >= 1.0 against z (short-only side never enters +1), exit at |z| <= 0.25, on a sign cross beyond the band, or after 60 sessions (re-entry allowed at the next signal date). M: state = sign(R) whenever |R| >= 10%, else flat (short-only: only R < 0).
- Weights: DAT leg 1/(1+beta), coin leg beta/(1+beta) (gross 1), beta = 60-session rolling OLS clipped [0.5, 3.0] known at the signal close; DAT leg equal weight over members valid at the refresh. Coin leg FBTC / ETHA from 2024-01-11 / 2024-07-23, spot BTC / ETH session prices before (short spot is hypothetical: Alpaca cannot short crypto, flagged).
- Costs: 10 bp per side per leg (20 bp check); spot-leg columns +15 bp (25 bp per side); borrow 3%/yr on every short weight (main), 15%/yr sensitivity. Cash-financed overlay (SHY weight 0); reported Sharpe is the overlay excess Sharpe; K2 sleeve = overlay + T-bill collateral.
- Windows: anchor 2024-01-08..2026-09-17, stress 2020-08-11..2023-12-29 (window starts at max(window start, first active signal); a window with < 60 active sessions is reported as not available, treated as stress pending).
- Tiers: runbook K1 (anchor >= 1.1882, stress >= 0.6447, 20 bp CAGR positive both), K2 (edge vs vol-matched S3 >= 0.05 both), watch_recent; DSR over 24 trials on the judged offset; random-entry placebo = 40 circular shifts of the position-state path inside the active span, must be matched or exceeded by <= 10% of placebos; 15%/yr borrow must leave the anchor CAGR positive.
