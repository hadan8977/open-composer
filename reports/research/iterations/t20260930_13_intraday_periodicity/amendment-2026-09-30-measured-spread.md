# 修正案 A1：连续竞价腿的价差改用实测报价（Opus 主审，2026-09-30 11:05 UTC，本任务任何结果出来之前写死并提交）

## 发现

`ml30.spread_estimate_from_ohlc` 是 21 日 Abdi-Ranaldo 估计，用日线高低收算。它在流动性好的股票上高估价差一到两个数量级。在 T-35 的面板里（`t20260929_35_overnight_persistence/cache/panel.parquet`，2024-01-08 起），它给出的价差是：

| 范围 | 估计价差 |
|---|---|
| P500 中位数 | 36 bp |
| P500 的 10% 分位 | 18.5 bp |
| AAPL | 26 bp |
| MSFT | 23 bp |
| NVDA | 50 bp |
| JPM | 25 bp |

而 AAPL 按约 $230 的股价，一个 1 美分的最小变动单位只有 0.43 bp。这个估计量在大盘股上量到的是日内波动的噪声，不是买卖价差。

## 影响

- **本任务（T-20260930-13）**：简报第 2 步按 hypotheses.md 用 h = 0.5 × AR 价差，这样算出的 RT1、tier 和净值**作废**，不作为判定依据。毛均值 m、t、安慰剂和对照不受影响。
- **T-20260929-35**：连续竞价路径的净值（`continuous_1x/2x`）同样作废。判定用的是竞价路径（每边 2 bp，不含价差），不受影响。
- **旧结论**：凡是在流动性好的股票上用这个 AR 估计判"成本吃光"的旧结论，都要复查。跳空回补 ≥$20M 档的关闭不受影响：C1 在官方竞价价上重算，毛边际只有 7.09 bp，没有用到 AR。

## 替代规则（本任务判定的依据）

- **价差来源**：Alpaca 历史 SIP 报价（NBBO，全国最优买卖报价），即 hypotheses.md"判定"一节"边缘"路径里本来就要做的实测，现在改为主路径。
- **抽样**：
  - 用 `numpy.random.default_rng(20260930)` 从主窗 2024-01-08 → 2026-09-29 的交易日中均匀抽 30 天，两个判定格用同一组日子。
  - 每个抽中的日子，取该判定格多头十分位和空头十分位的全部股票。
- **取价时刻**：T = 15:30:00 ET（收盘段 C 的进场）和 10:00:00 ET（开盘段 O 的出场）。
  - 先取 [T−5 秒, T) 内的最后一个有效报价：bid > 0 且 ask > bid，剔除交叉或锁定的报价。
  - 没有的，再取 [T−60 秒, T)；仍然没有的，记缺失并报告比例。
- **计算**：
  - 每个（股票, 日）的半价差 = (ask − bid) / (ask + bid)。
  - h_多、h_空：先对同一天的股票取均值，再对 30 天取均值。
  - RT1 = h_多 + h_空 + 8 bp（连续竞价腿和竞价腿各每边 2 bp，与 hypotheses.md 相同）。
- **分档**：
  - **关闭**：m < RT1，或 Newey-West t < 2.0，或安慰剂打赢 < 0.90。
  - **通过**：m ≥ 2 × RT1，且 t、安慰剂都过。
  - **边缘**：RT1 ≤ m < 2 × RT1。实测已做，不再补测；只记录，不建账本。
- **取数**：
  - 复用 `scripts/run_t20260930_11_gap_fade_auction.py` 的 `DataSession`：凭证只放在请求头里，每秒不超过 3 次请求，遇到 429 退避。
  - 接口 `https://data.alpaca.markets/v2/stocks/quotes`，参数：
    - `symbols` 每批不超过 100 个；
    - `start`、`end` 用 RFC3339；
    - `feed=sip`，`limit=10000`；
    - 翻页跟随 `next_page_token`。
  - 不打印、不保存任何凭证。
- **适用范围**：以后主线 C 的日内测试一律用实测报价。dv21 ≥ $20M 的股票不接受日线 AR 估计作为"逐只实测价差"。

## 不变的部分

池、信号、候选、窗口、毛收益定义、安慰剂、对照、t 门槛都不变。本修正案只替换成本里的 h。
