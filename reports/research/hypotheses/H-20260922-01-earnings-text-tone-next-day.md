# H-20260922-01 财报文本语气 → 次日开盘进、次日收盘出：先影子后模拟盘

- 状态：approved（Fable 2026-09-22 裁定；阻塞项：打分模型端点）· 假设族：earnings_text_next_day（新族，预算 4）· 层：选股（事件驱动，日内持有）· 数据层：**一级**（8-K Item 2.02 新闻稿文本；可选电话会文本）
- 上一环：H-20260916-06（PEAD + LLM 读 8-K，proposed 未跑）。本卡把它收窄成一个已有 2026 年论文规则的、三周内能前向验证的版本；H-06 的 XBRL/分析师预期部分不做。
- 一句话假设：财报公布后，LLM 对文本语气的打分在**第一个可交易开盘之后**仍然预测当日开盘→收盘的收益；Q5−Q1 每事件 ≥ 40 bp（论文报 153 bp，我们按更保守的成本与免费文本打对折再打对折），long-only Q5 在 20 bp/边成本后为正。

## 情报（四问）

1. **新不新**：Yu, Liu, Zhang, He《Fast Numbers, Slow Language》arXiv 2606.29734，2026-06-29 提交；样本 S&P 1500，2022–2025，测试集 2024–2025 共 2,468 事件。近到不能再近。
2. **第三方复现**：无。论文自己用三个模型交叉验证（GPT-5-mini IC 0.11；Claude Haiku 4.5、Gemini 3 Flash 各 IC 0.08）。同方向的独立论文：EAR-AI（2026-05，SSRN 6712298，全文未取得）、NBER w35093（2026-04，月度尺度）。反面：Kim-Muhn-Nikolaev 2024 已撤回；Profit Mirage 与 Glasserman-Lin 证明截止日之前的回测可能是记忆。
3. **有没有人做出来并分享**：代码仓库 `piqueyd/Fast-Numbers-Slow-Language` 只有 README；数据受许可限制。没有公开实盘记录；AIEQ（AI 选股 ETF）跑输指数但机制不同。
4. **本机能不能跑**：能。文本处理不吃内存；分钟线 2016–2026 已有，次日开盘→收盘收益零成本可算；8-K 接受时间戳来自 SEC submissions API，免费。缺两样：打分模型（用户给 API key）、电话会文本（可选付费）。

**最便宜的决定性测试**：不是历史回测（躲不开模型记忆），而是**前向影子**：从 2026-10-13 Q3 财报季开始，对每份 8-K Item 2.02 在接受后 30 分钟内打分并落盘，等价格出来再算。5 周约 1,200 个 S&P 1500 事件。到 11-14 如果 Q5−Q1 < 40 bp 或 long-only Q5 净收益 ≤ 0，否定。历史样本（2024-01 起）只用来调通流程和给出量级参考，明确标注可能有记忆污染。

## 设计（跑之前写死）

- 事件：8-K 含 Item 2.02 的申报，取 EX-99.1 新闻稿全文（免费）；可选：电话会文本（需付费源，作为第二列）。
- 可见时点：`acceptanceDateTime`（SEC 原始时间戳）；前向阶段另记本地 `fetched_at` 和 `scored_at`，以后者为准。
- 入场：可见时点之后**至少 60 分钟**的第一个常规交易时段开盘（盘前 8:30 前接受 → 当日开盘；之后 → 次日开盘）；出场：同一交易日收盘。另报持有 +1、+5 日。
- 打分：固定提示词，输出 −1..1 的语气分、指引方向（上调/维持/下调/无）、一句依据；**实体中性化**（去掉公司名、代码、日期）以降低记忆效应；模型与提示词的 SHA-256 冻结在 manifest 里。
- 组合：按当日事件的分数五分位；报 Q5−Q1、long-only Q5 等权；成本 10 / 20 bp 每边两档。
- 基线：只用价格的"开盘跳空 + 相对成交量"信号做同样的五分位，回答"文本有没有超出价格的信息"（NBER w35093 的逻辑）。
- 占位：(a) 把同一天事件的分数随机重排，5 个种子；(b) 把文本随机错配到同日其它公司再打分（抽样 200 份）。
- 必报：SPY / MTUM / SPMO 同期、同波动超额、占位；事件数、被跳过的事件及原因（文本缺失、无分钟线、停牌）。

## 否定条件

- 前向 ≥ 400 事件后 Q5−Q1 < 40 bp/事件；或
- long-only Q5 在 20 bp/边成本后 ≤ 0；或
- 分数重排占位达到真实 Q5−Q1 的 50% 以上；或
- 价格基线的五分位已经解释掉文本分数的一半以上。
