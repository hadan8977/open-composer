# H-20260916-02 新闻注意力特征：先不用 LLM，把 68 万条新闻变成截面特征

- 状态：approved（按 2026-09-16 委托；第二阶段需你确认 token 预算）· 假设族：news_attention_features（本卡计 1 次，族预算 6）
- 层：选股（截面特征）· 数据层：**一级**（新闻），样本仅 2024-01 → 2026-09（≈140 周，小样本要单独标注）
- 一句话假设：在动量 top500 股票池里，"新闻数量突增 + 内容新颖"的股票与"无人报道"的股票，其后 1–4 周收益分布不同；
  作为特征加入排序模型或作为门控，能给规则动量带来增量。

## 为什么用这个方法（出处）
- 文本信号是 LLM 在量化里证据最扎实的一类，但第一步不需要 LLM：注意力/新颖度这类计数特征就有文献效应，且成本为零。
  【lit:llm_extracted_signals_10k_earnings_calls_verified；lit:breadth_qd_open_attention_reversal_cost】
- 我们已有的资产：`data/features/news_packets/` 68.5 万条（含 symbols / headline / summary / visible_at，点时字段齐全）。
  LLM 事件抽取脚本因外部端点失效停在 5 条，所以本卡把"不需要端点"的部分先做完。【`scripts/extract_news_events_llm.py`】

## 设计
- 第 1 阶段（无 LLM）：每股每日特征：过去 1/5/20 日新闻条数及其相对该股 60 日均值的倍数（注意力突增）；来源数；
  标题去重后的"新颖度"（与该股过去 20 日标题的 3-gram 重合率）；是否含财报/指引/并购/诉讼等关键词（规则词典，非 LLM）。
  可见时间严格用 `visible_at`，特征只在次一交易日开盘后生效。
- 进现有筛选器（IC / ICIR / FDR / 符号稳定性），再做孪生单元：规则动量 ± 注意力门（突增且新颖 → 保留；无报道 → 减半）。
- 第 2 阶段（需要你确认预算）：用 Anthropic 模型对**样本**打分（每周入选的 50 只 × 当周新闻，约每周 2–5 千条），产出情绪与事件类型，
  与第 1 阶段特征对比增量。不批量跑 68 万条。
- 占位：把每条新闻的 symbols 随机重排到同池其他股票，重算特征。

## 预期与否定判据
- 预期：注意力突增特征在 recent 窗 ICIR > 0.1，且门控后同波动超额改善 ≥ 2 个百分点（样本短，标准比内部人卡低）。
- 否定：(1) 特征 0 项过 FDR；(2) 占位版本效应相当；(3) 门控使换手上升而超额不升。
- 必报：SPY / MTUM / SPMO / 同波动超额 / 占位；并标注"2024→ 小样本"。
