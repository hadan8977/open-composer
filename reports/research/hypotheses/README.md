# 假设卡（Hypothesis cards）

每张卡是一次可被推翻的实验。状态流转：proposed → approved（你批准或按 2026-09-16 的委托默认批准）→ running → done（写复盘卡到 `../lessons/`）。
规则（来自 `docs/proposal-research-loop-redesign-2026-09-15.zh.md` 2.4/2.5）：
- 方法一栏必须引用 `knowledge/digest/` 里的条目或有 URL 的来源；没有出处的卡不合格。
- 必须写"什么结果算否定"和占位设计；缺一不能批。
- 每张卡只改一处（一个数据层、一个目标或一个模块）。
- 试验计入 `trial-families.json` 的假设族；DSR 用族的累计计数算。
- 评分函数和门槛定义只有用户能改。
- 复盘必须报 SPY / MTUM / SPMO / 同波动超额 / 占位五个数。

## 情报节是必填的（2026-09-18 起）

每张新卡在"设计"之前必须有一节 **情报**，四个问题各一行，引用 `reports/research/intel/` 下的简报：

1. 来源最后更新时间、基准数字的市场与时间段（新不新）；
2. 第三方复现状况（没有就写"只有作者自己说"）；
3. 有没有人已经做出来并分享（净值曲线、对账单、可运行代码 + licence）；
4. 在本机（3.9 GB 内存 / 2 核 / 无 GPU / 无 torch）与本地数据上能不能跑，不能跑的部分写清楚。

再加一行 **最便宜的决定性测试**：如果这个假设是错的，哪个最小的测试最快把它否掉，预计跑多久。
没有情报节的卡不许开始跑。理由见 `reports/research/intel/README.md`。
