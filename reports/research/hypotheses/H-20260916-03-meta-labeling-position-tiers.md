# H-20260916-03 元标签仓位分档：让模型只决定"这只要不要拿、拿多大"

- 状态：**done（2026-09-16，被否定）** · 假设族：meta_labeling_on_rule_momentum（实际计 2 次：逻辑回归与 LightGBM 两个可被选中的变体，族预算 6）
- 结果：命中否定判据 (2) 与 (4)。证据 `reports/research/iterations/h20260916_03_meta_label/report.md`，复盘 `reports/research/lessons/L-20260916-03-draft.md`。同波动 SPY 超额确实改善了 6.1 / 7.7 个百分点，但 5 个种子的占位平均拿到了其中 99% / 51%，且 CAGR 掉了 12.9 / 10.3 个百分点——分档在“相对组合中位数”的标签下等价于按比例去杠杆，不是过滤器。
- 层：信号接受（acceptance）· 数据层：二级（现有价量 + 组合内部状态），不引入新数据
- 一句话假设：在规则动量 top50 的每周持仓上，用一个二级模型预测"这只股票未来 4 周是否跑赢组合中位数"，按概率给 0 / 1% / 2% 三档仓位，
  能在不降低 CAGR 3 个百分点以上的前提下，把最大回撤和同波动 SPY 超额显著改善。

## 为什么用这个方法（出处）
- 元标签是文献里唯一让"规则在前、模型在后"站得住的位置：一级信号定方向，二级模型只管过滤与仓位。【lit:us_mom_minute_p1_003_frozen_ml_review:meta_labeling_scope】
- 我们自己的证据：同一批特征上让模型直接选股，4 个 ML 单元全部输给规则孪生（如 exp:step13_m1_single_cell_reversal_trend_uni500_k50_gate_on 的规则孪生 CAGR 33.7% vs ML 4.4%）。
  所以不再让模型选股，只让它砍掉坏持仓。【exp:step13_*】
- 它不是万能药，文献里有"元标签并不总是提升信号效力"的反例，所以否定判据要写死。【`reports/research/control/research-loop-designs-survey-2026-09-15.md` §6】

## 设计
- 一级信号：现有规则动量（mom_252_21 / vol_63，前 500 ADV，前 50，周频，等权）。不改。
- 样本：每周每只入选股票一行，2016 → 2026 年 8 月；标签 = 未来 4 周超额（相对组合等权中位数）是否 > 0。
- 特征（只用入选时刻已知的信息）：该股动量分位、63 日波动、过去 4 周相对组合的超额、入选连续周数、距 52 周高点、隔夜/日内收益比、
  组合层状态（SPY 距 200 日线、截面宽度）。
- 二级模型：逻辑回归（基线）与 LightGBM 二分类；训练滚动 3 年、验证留出 1 个季度、隔离期 4 周；每季重训。
- 仓位：p < 0.4 → 0；0.4–0.6 → 1%；> 0.6 → 2%；剩余现金 BIL。对照：等权 2%（现在的做法）。
- 占位：把标签在时间上随机平移（保持每周的正负比例）重训一次，仓位分档效果应消失。

## 预期与否定判据
- 预期：最大回撤从 -28% 改善到 -22% 以内；同波动 SPY 超额从 -11% 改善 ≥ 3 个百分点；CAGR 不低于 30%。
- 否定（任一命中即停）：(1) 同波动超额改善 < 3 个百分点；(2) 占位版本改善幅度达到真实版本的 50% 以上；
  (3) 验证集 AUC < 0.55 且符号在四个滚动窗里不稳定；(4) 三档换手使净 CAGR 低于等权基线 3 个百分点以上。
- 必报：SPY / MTUM / SPMO / 同波动超额 / 占位。

## 成本与执行
- 工程：内核需要导出"每次调仓的持仓 + 特征 + 后续 4 周收益"（`run_experiment` 目前只在内存里算权重表），约 1–2 个执行者工作日；
  训练与评估本身分钟级，日线、4 GB 内可跑（`scripts/run_capped.sh --mem 1.8G`）。
- 产出：`reports/research/iterations/h20260916_03_meta_label/`（导出表、模型、评估、占位、对照表）+ 复盘卡。
