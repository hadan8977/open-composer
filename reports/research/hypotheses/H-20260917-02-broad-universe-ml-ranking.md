# H-20260917-02 全池截面 ML 排序：目标先定、特征跨层、月频，这是"ML 策略"的主线

- 状态：on hold（2026-09-22 Fable 裁定，见 I-20260922-01 第 3 节 D 行；原 2026-09-17 approved 不代表现已可训练）· 假设族：ml_ranking_broad（预算 6，每个可被选中的模型×目标组合计 1 次）· 前置依赖：D-20260917-01；特征来自 H-01/H-05/H-07 的数据管道
- 2026-09-22 说明：纯价量特征上的 ML 排序先验低（Avramov-Cheng-Metzker；本地 4 个 ML 单元全输规则孪生）；等 H-20260922-01 产出文本特征后再评估是否重开。
- 层：选股（独立策略）· 数据层：一级 + 二级
- 一句话假设：在全体可交易美股上，以"未来 21 个交易日剔除市场与规模后的超额"为目标，用跨层特征（价量派生、内部人、13D、空头兴趣、新闻计数）训练排序模型（LambdaRank / 梯度提升二分类），
  样本外前 10% 组相对后 10% 组的月超额显著为正，且优于任何单一规则孪生（动量、内部人）。
- 为什么现在才能做：此前 ML 输给规则是因为特征只有价量、池子只有前 500；文献里 ML 优先的做法（Gu-Kelly-Xiu）是全市场 + 多信息源 + 定义清楚的目标。
- 设计：
  - 目标：21 日超额（剔除 SPY beta 与规模分组均值）；备选：是否进入截面前 20%（分类）。
  - 特征：动量/反转/波动/换手/隔夜日内比；内部人 30/60/90 日买卖计数与金额、角色、集群；13D 新申报 60 日内；days-to-cover；新闻计数。全部点时。
  - 模型：LambdaRank（按月分组）与 GBDT 二分类；岭回归基线；训练滚动 3 年、验证留出 1 季、隔离 21 日、每季重训。
  - 组合：前 10% 等权（或按流动性段限制单只权重），月频；对照：同尺寸随机、动量孪生、内部人孪生、SPY/IWM。
  - 诚实：打乱标签占位 ≥ 5 个种子；试验族计数含所有模型×目标组合；特征重要性按层报告，回答"增量来自哪一层"。
- 否定：验证集 RankIC < 0.02 或占位达到真实的 50%；或前 10% 组的同波动超额不优于最好的规则孪生。
- 必报：SPY / IWM / MTUM / SPMO / 同波动超额 / 占位分布 / 按层的特征贡献。
