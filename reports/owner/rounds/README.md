# 自动轮汇报存档

每个自动轮把最后发给机主的汇报写成一个文件，和本轮其他改动一起提交（手册 `docs/runbook-autonomous-round.zh.md` 第 7 节第 6 步）。看板的报告页和每日邮件从这里读取。

- 文件名：`<YYYY-MM-DD>T<HHMM>Z-<lead|exec>.md`，时间是本轮开始的 UTC 时间，例如 `2026-10-05T0107Z-lead.md`。
- 第一行：`# 主审轮 2026-10-05 01:07 UTC` 或 `# 执行轮 …`。
- 正文结构和发到对话里的汇报相同。主审轮写五段：这一轮做了什么、结果、模拟盘值守、下一轮做什么、需要你决定的；执行轮写三行。
- 跳过的轮不写。
