# Phrase candidates

A phrase is worth editing when it adds no meaning, overstates evidence, or repeatedly delays the point. Match context, not a blacklist.

| Candidate | Check before editing |
| --- | --- |
| “It's worth noting,” “here's the thing,” “at its core” | Remove if empty; keep useful framing or recognizable voice. |
| “Revolutionary,” “game-changing,” “transformative” | Retain only when the source supports that strength; do not invent a result to replace the claim. |
| “Leverage,” “utilize,” “facilitate” | Prefer a plain equivalent when meaning survives; preserve accurate technical terms. |
| “Actually,” “simply,” “quietly,” “just” | Keep literal meaning, correction, emphasis, and character; cut empty repetition. |
| “Experts agree,” “studies show” | Check attribution. Flag missing support instead of creating a source or silently upgrading the claim. |
| “Important,” “significant,” “robust” | Check whether the word has a defined meaning or supported effect, including statistical or technical usage. |

Preserve meaningful qualifiers such as “may,” “most,” “approximately,” and “usually.” The goal is clearer wording with the same claim.
