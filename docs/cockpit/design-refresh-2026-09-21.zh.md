# Cockpit 设计刷新：冷色、深色优先、留白与动效 — 2026-09-21（第三稿）

> 机主 2026-09-21 对上一稿（暖纸墨 + 衬线标题 + 颗粒）的反馈：字体丑；排版局促、信息量爆炸、读起来力竭；纸和墨色太常规、早已不流行；不喜欢 Claude 产品页那种风格；想要更冷、更新的 AI-native 感觉，参考 agent 工具、IDE 与现代网站；流畅的交互、跳转和过渡动画很重要。
>
> 本稿据此整体重做，暖纸墨方案作废（第 6 节保留作废原因，便于以后不再走回头路）。

## 2. 令牌（`open_composer/cockpit/static/css/cockpit.css` 顶部）

- **画布**：深色 `#0b0d11 → #12151b → #181c23 → #20252e`（画布 / 卡片 / 凹陷 / 分隔）；浅色 `#f5f6f8 → #ffffff → #eef0f3 → #e2e5ea`。画布左上有一道极淡的强调色径向光（深 14% / 浅 7%），只有这一处"发光"。
- **文字**：深色 `rgb(232,234,240)`、浅色 `rgb(15,18,24)`，四档 100 / 62 / 42 / 22%。
- **线**：发丝线 `rgba(ink, .07)`，强线 `.14`；所有容器用 1px 内发丝线，不用投影；投影只给悬浮层（窄屏检视器、抽屉、底部标签栏）。
- **强调色**：深色 `#7c8cff`，浅色 `#4f5eff`；只用于选中、链接、工具芯片、当前导航。
- **四个状态色**：ok `#3ecf8e / #17a366`，warn `#f5a524 / #d9880f`，stale `#ff6166 / #e5484d`，unknown `#6f7683 / #8b93a1`（深 / 浅）。状态永远是"点 + 词"，点带一圈 16% 的同色光晕；芯片描边 + 8% 底色。
- **字**：Geist（本地 `static/fonts/`，仅拉丁子集 29 KB + 等宽 23 KB，`font-display: swap`，中文回落到 PingFang / Hiragino / YaHei）。正文 14px / 1.5；页标题 22px 600 -0.02em；大数字 30px 600 -0.03em 等宽数字；小标签 11px 500 大写 +0.06em。**没有衬线。**
- **圆角**：14 / 10 / 6（容器 / 控件 / 芯片）。

## 3. 密度（回应"局促、信息量爆炸"）

- 内容区内边距 28 × 36，最大宽 1120；指标卡最小高 94，上下留白 30；分区标题上方 30、下方 10。
- 列表行最小高 54、内边距 11 × 18；行标题 14px、副标题 12px 一行截断；右侧只放一个数字 + 一个词。没有可计数的行**不再**显示"–"。
- 顶栏只剩六件事：Claude 状态、Codex 一个词、fresh 5h、agents 一个计数、data 一个点、auth 一个倒计时；手机上再去掉 Codex。
- Hypotheses 的每条泳道是一个可折叠的 `<details>`，已完结泳道（refuted / on hold / data card / unclassified）默认收起；输入过滤词时自动展开。
- Agents 行副标题只剩 `provider · model · 当前文件`；Paper 行副标题只剩 `cycle · ago · fill`。
- 侧栏快捷键提示默认隐藏，悬停侧栏才出现。

## 4. 动效（回应"流畅的交互、跳转和过渡"）

- **跳转**：跨文档 View Transition（Chrome / Edge 126+、Safari 18.2+）。侧栏、顶栏、手机头、标签栏各自命名，跳页时原地不动；内容区旧页 140ms 淡出、新页 260ms 上浮淡入。不支持的浏览器就是普通跳转。
- **进场**：内容区各块按 30ms 递增错开上浮；列表行前六行按 20ms 递增错开。
- **检视器**：从右侧 18px 滑入，300ms，`cubic-bezier(.32,.72,0,1)`。手机抽屉从下方弹起 340ms 同一曲线，背景 35% 黑 + 6px 模糊。
- **悬停 / 按下**：行悬停 3.5% 墨色底；导航项、关闭按钮、标签按下缩到 0.985 / 0.92；指标卡悬停上浮 1px。
- **活体**：运行中的圆点外圈 2.2s 脉冲；SSE 连上时时间线标题旁出现绿色 "live"；新到达的时间线行上浮进入；进度条宽度 500ms 过渡；computing 用骨架闪光。
- **过滤**：血统图不匹配的节点 / 边 180ms 淡到 16% / 10%；过滤框聚焦时宽度从 190 展到 240，带强调色外圈。
- `prefers-reduced-motion: reduce` 时全部关闭（含 View Transition）；`prefers-reduced-transparency` 时玻璃退化为不透明。

## 4b. 名字与切屏（2026-09-21 晚补）

- **名字改为 Quant**（域名 `quant.hadan.blog`，机主不喜欢 cockpit 这个词）：侧栏品牌、页面标题、主屏幕图标名、favicon 与侧栏的标记都改成 Q 形（圆 + 尾巴），代码里的模块名 `open_composer.cockpit` 不动。
- **切屏不再整页刷新**：机主在手机上经隧道访问时，每次点侧栏都要等好几秒。本机渲染每屏只要 0.2–0.8 s，慢的是链路：一次整页导航 = HTML 一趟 + CSS 一趟 + 字体一趟 + 脚本一趟，串行三四个往返，而且跨文档 View Transition 会把旧页冻住直到新页就绪，看不到进度。现在：
  1. 静态资源带内容哈希 `?v=`，响应头 `Cache-Control: public, max-age=31536000, immutable`（`_ImmutableStaticFiles`），浏览器与 Cloudflare 边缘都能长期缓存，一次导航只剩 HTML 一趟。
  2. 首屏画完 300 ms 后并行预取另外五屏的 HTML 存在内存里；点侧栏 / 标签栏 / ⌘1-6 时就地替换内容区、标题、顶栏状态项与激活态（同文档 View Transition），不再整页加载；每次切换后把其它屏的旧副本（超过 120 s）在后台刷新；再点当前屏 = 重新拉取；页面从后台回到前台且副本过期时自动刷新当前屏。需要走网络时顶部出现 2px 强调色进度线。
  3. 详情页、`/v2/`、边缘会话过期（fetch 被 302 到登录页）一律退回整页导航；无 JS 时链接照常可用。
  4. 实测（本机 Playwright，桌面 + 手机）：整个会话只有 1 次 document 请求，其余五屏由预取覆盖；切换 160–500 ms（含 400 ms 过渡动画）；检视器深链在后退时恢复。

## 5. 可调的旋钮

想更冷 / 更暖：改 `--bg` 四级与 `--ink`。想换强调色：只改 `--tint` / `--tint-2`（`--tint-bg` / `--tint-ring` 跟着改 alpha 即可）。想更密：`.row { min-height; padding }`、`.metrics { margin-bottom }`、`.section { margin }`。想更慢或更快：`--ease` / `--spring` 与各 `animation` 时长。光晕：`--glow`。切屏副本的保鲜期：`cockpit.js` 里的 `FRESH_MS`（默认 120 s）。

## 6. 作废的暖纸墨稿（为什么不回去）

第二稿用了羊皮纸底 `#f4f2ed`、暖炭深色、系统衬线标题、SVG 颗粒。机主的判断：衬线丑、纸墨常规过时、颗粒和暖色让画面发闷；且把"质感"寄托在材质上会让信息密度显得更高。本稿把质感换成对比、留白与运动，材质只剩玻璃控制层与一道光。Claude 产品页与 Cursor 官网的奶油色都不再作为参考。
