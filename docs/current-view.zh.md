## 2026-09-19 第三轮：把菜单机械化这条路走到头了，但捡到一条真结论

卡：`H-20260919-01`（96 cell，16 族）。教训：`reports/research/lessons/L-20260919-01.md`。

**作为上线候选：否定。** 16 个族没有一个打过已经在模拟盘上跑的行业 sleeve 的 anchor 夏普 1.361，最高 1.206。有 8 个族的 anchor 年化超过 27.8%（最高 64.0%），但全部靠 -32% 到 -40% 的回撤换来，夏普一个没过。预注册写的是"年化和夏普同时满足"，所以结论没有模糊空间——这正是把判定写成"同时"而不是"或者"的价值，只写高年化的话这张卡会被当成成功。

**捡到的真结论：06 号卡那句话是错的，现在改对了。**

06 号卡说「横截面动量需要一个**风险同质**的候选集」。按年化波动率划绝对区间确实做到了风险同质（持仓中位波动落在带内，两种退化被构造排除），但那样的带里装的是 SVXY（反向 VIX）+ TBF（反向长债）+ EWW（墨西哥）+ GSG（商品）——波动率一样，风险来源毫不相干，"最近涨得最多"就等于"哪个资产类别刚跑完一波"，而那要均值回复。

加一条"与 SPY 的 250 日相关系数 ≥ 0.70"之后，同一个（波动带 × 打分）配对比较：

| | 无约束 → corr≥0.70 |
|---|---|
| 留出窗夏普中位数 | 0.587 → **1.188**，**8 对 8 全部变好** |
| 选择窗夏普中位数 | 1.006 → 0.842，6 对变差 |
| 安慰剂赢过比例 | 6 对变好，加约束后 4 个族是 **0.00** |

**约束伤害了用来做选择的窗口、帮助了完全没碰过的窗口——这是去掉过拟合的特征，不是加上过拟合的特征。** 正确的说法：**需要的是共享同一个公共因子的候选集，波动率可比只是副产品。** 11 个 SPDR 行业能工作是因为它们是同一个市场的切分，不是因为波动率相近。

削弱条件一起记：8 对不是 8 个独立检验（共用标的和日历），留出窗只有一个约 180 个交易日的窗口。

**第三次栽在同一件事上：二阶矩的滤网挡不住尾部不对称。** 波动率带 + 相关性下限全过的持仓里有 TECL / SPXL / TQQQ / FAS（3 倍杠杆，与 SPY 相关性接近 1，波动率 32-48%）和 SVXY / SVIX（做空波动率本质是带杠杆做多股票，所以相关性高、滚动波动率只有 22-24%）。SVXY 在 2018-02-05 单日 -90%，24% 的滚动波动率毫无预警。06 号卡按名字排除时 BITO 以 34% 波动率漏过；这张卡按波动率和相关性排除时 TQQQ 照样漏过。**杠杆和做空波动率产品必须按招募说明书的杠杆倍数和产品类别排除，不能靠名字、波动率或 beta。**

下一张卡的假设很具体：11 个 SPDR 行业还有一个性质是相关性下限复制不出来的——**穷尽且互斥**。相关性下限给出的是 73-97 个互相高度重叠的名字（SMH / IYW / SPMO / TECL 是同一个赌注的四个版本），本卡的两两相关上限 0.95 太松等于没约束。下一步：在 corr≥0.70 的候选集里把两两相关上限压到 0.80，并按杠杆倍数排除，看能否把 `midvol / r252 / corr≥0.70`（留出窗夏普 1.498、安慰剂 0.00，但 anchor 夏普只有 0.795）抬过 1.361。抬不过就承认行业菜单的价值在"人为设计的穷尽互斥切分"里，把精力放到别处。

## 2026-09-18 第二轮：去掉手挑菜单的 ETF 池化测试被否定，但机制有用

H-20260918-05 自己写明最弱的一点是三个菜单由我事后挑选。所以我把菜单整个去掉，候选集换成纯机械的点时规则（所有基金里历史 ≥250 个交易日、滚动 60 日日均成交额 ≥2000 万），96 个 cell、8 个族预注册。

**结果：八个族的最优 cell，选择窗夏普全部低于 SPMO 的 1.46，最高才 0.95。去掉菜单让结果显著变坏。**

持仓诊断直接看出两个方向相反的退化：

- **除以波动率 → 买国库券。** 留出窗夏普最高的那个 cell（2.91）实际持仓是 USFR / SGOV / BIL / SHV / BILS / TBIL，持仓波动率中位数 0.29%，年化收益 6.7%，回撤 -0.6%。这是活期存款账户，不是策略。**夏普单独拿出来不能当选择标准。**
- **不除以波动率 → 买最高杠杆。** 持仓是 SOXL、2 倍美光、2 倍英伟达、3 倍金矿、2 倍 Coinbase、2 倍比特币，波动率中位数 100% 年化，回撤 -58% 到 -75%。这不是轮动，是把最高杠杆押在最近最猛的单一标的上。

**真正学到的**：截面动量需要一个**风险同质**的候选集。行业 ETF 那一档能成，是因为 11 只全是 1 倍、风险可比的股票基金，排名比较的是信号而不是杠杆。菜单不只是事后视角，它同时是风险同质化这一步。下一张卡把分组也机械化：先按滚动波动率分档，再在同档内部排名。
