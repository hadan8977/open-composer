# OpenComposer 研究目标与项目结构

OpenComposer 面向一个有实际资金约束的美股及 ETF 账户。研究的用途是发现、复现和独立验证近期扣除交易成本与融资后的收益来源，使通过验证的策略可以进入授权模拟盘。最终看相对现金的超额 Sharpe、能实际持有的杠杆、净美元、年化回报和回撤。高双位数至翻倍级年收益是研究目标；报告须给出实际达到的水平和不确定性。

## 市场问题和数据

研究人员可以从论文、交易者公开的完整策略、既有实验、自己的交易和未成交机会出发。资产、市场状态、数据粒度、持有期和模型由机制决定。个股盘中纯量价、事件驱动、隔夜、波段和月度配置均可成为主线。分钟线可以参与选股、判断何时进出以及何时放弃。模型可从可解释因子、线性或树模型起步，价格路径的顺序若有意义，可比较序列模型。比较对象共享数据时钟、机会和成本。

研究须区分几种信息。成交量、价格、波动率、价差和市场广度描述交易环境；新闻情绪、关注度、分歧和报道新颖性各有独立含义；公司公告、财报、附件、修订及分析师预期需要映射到当时的发行人、证券与财季。给来源建可检查的覆盖分母，保留首次可见版本、获取时间和缺失原因。公开原文时刻、系统取得时刻、模型可用时刻、委托及成交分别记录。数据采购和新增模型预算须获单独授权。

## 现有项目结构

下表说明主工作区的逻辑边界。私有证据与运行数据由各自环境保存，公开仓库不承担这些数据的分发。

| 位置 | 现有职责 |
| --- | --- |
| `AGENTS.md`、`docs/`、`control.json` | 入口、机主偏好、研究与账户权限、项目开关 |
| `research/` | 课题登记、原始依据、试验、已见样本、研究决策与发现 |
| `open_composer/`、`scripts/` | 证券及事件数据、因子、扫描、执行回放、账务和研究命令 |
| `strategy_specs/`、`config/`、`harness/`、`prompts/`、`.agents/skills/` | 策略定义、评价与角色约定 |
| `reports/`、`data/` | 运行证据及数据入口；部分历史位置承担恢复依赖 |
| `deploy/`、`frontend/` | 授权模拟盘运维、只读展示 |
| 主仓库之外的市场数据、归档和运维目录 | 原始数据和版本、恢复包、研究决策交接、权限与部署边界 |

本机负责研究，模拟盘运行环境独立。自动研究暂停时保留历史断点；重新开始由机主决定。模拟盘使用原有授权。实盘写入不在本项目当前研究授权内。

## 建议的自动研究方式

1. **选一个会改变决定的问题。** 写清谁在何时掌握什么信息，目标是预测、排序、入场、退出、执行还是资金分配；列出最可能推翻解释的情形。比较下一笔预算投向本题或其他机会的价值。
2. **先复原再改编。** 对有代表性的同一股票日，按原作者的机会池、信号可见时刻、挂单、成交、退出及成本一路复原。用第一处分歧解释两种结果。证券覆盖、买卖方向或数据精度不同，保留可归因的边界。
3. **观测市场如何演变。** 如要择时，在同一机会、资金与退出规则上比较静态决定和基于新信息的决定，计入错过的赢家、少做的亏损交易、未成交和剩余头寸。检查买入时实际可知的信息。固定钟点适用于有时钟依据的机制。
4. **逐层评价。** 因子看同期增量预测、覆盖和衰减；模型在历史成熟标签上逐期训练，报告向前预测与同信息基线；策略看成交、费用和同条件反例；账户在共同购买力和融资约束下连续回放。保留所有已试变体与选题接触过的数据，冻结后才使用受保护的独立验证。
5. **用失败推进选择。** 指出哪个解释已排除、哪个仍有价值、什么便宜的证据足以改变判断；没有值得继续的判别时，明确停止投资及原因。将结论送回原课题和下一次择题。
6. **交付与分工。** 决策角色选择问题、审阅实质变更及晋级，执行角色实施、复核和汇报，机械工作交给廉价模型。保留两个常驻会话和总预算。研究结论、项目改进和模拟盘进度分别陈述；同类问题比较端到端用时、模型实际用量、返工和产物质量。

## 结构变更的判断

建议先调整决策指令、来源覆盖与失败后接续，复用现有行情、逐笔回放、资金与恢复路径。更大规模的替换需同题比较证明价值。用已见案例验证兼容性，以未用于设计的事件评价研究质量，单列迁移成本。若证据或成本不支持新结构，可沿原实现恢复。本文是项目设计说明，运行授权以工作区有效开关和机主决定为准。
