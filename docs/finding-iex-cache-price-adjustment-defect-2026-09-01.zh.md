# 发现：IEX 缓存的价格调整缺陷，及其对历史结论的影响范围

日期：`2026-09-01`
发现者：SIP 迁移过程中的 P1b 回归交叉验证
状态：已确证，已量化，影响范围已界定

---

## 1. 一句话

**本仓库退役的 `data/cache/*_iex.csv` 是以 Alpaca 默认的 `adjustment=raw` 抓取的**，
既没有拆股调整也没有分红调整。因此所有读这些文件的回测都存在两个系统性错误：
杠杆 ETF 的收益序列里混入了**根本没发生过的 -50% 暴跌**，而现金腿的收益被记成了 **0**。

这不是推测。下面每个数字都可以用 `datasets/legacy-iex-cache` 里的归档重现。

---

## 2. 怎么发现的

P1b 把 `scripts/evaluate_vol02_recalibrated.py` 提炼成通用 harness 后，
同一条 VOL02 规则、同一个 OOS 窗口（2022-01-03 起），换到 SIP 数据上结果反转：

| 指标 | IEX（原始记录，commit `a38c349`） | SIP（`adjustment=all`） |
|---|---:|---:|
| 2024-26 CAGR | **-7.96%** | **+18.86%** |
| MAR | 0.071 | 0.783 |
| CAGR vs QQQ | -9.5pp | +7.0pp |
| 正折数 | 2/5 | 3/5 |
| 未过门槛数 | 6/8 | 2/8 |

先排除了"重构改变了行为"这个解释：把 **IEX 数据喂进新 harness**，
17 位浮点精度完全复现原始数值（`sharpe_excess_bil = 0.35248398502299755`，
`positive_fold_count = 2`，`stitched_oos_row_count = 1150`，
`qqq_correlation = 0.4922845044400049`）。**代码等价，差异 100% 来自数据。**

---

## 3. 缺陷一：未调整的拆股 = 幻影暴跌

原始 IEX 序列里单日跌幅超过 30% 的记录：

```
TQQQ  2021-01-21   199.01 ->  101.58   -49.0%    <- 2:1 拆股
TQQQ  2022-01-13   152.34 ->   70.24   -53.9%    <- 2:1 拆股（落在 OOS 窗口内）
TQQQ  2025-11-20    99.98 ->   46.51   -53.5%    <- 2:1 拆股（落在 OOS 窗口内）
TQQQ  2025-04-09    38.96 ->   52.62   +35.1%    <- 真实行情，非拆股
QLD   2020-08-18   181.98 ->   92.81   -49.0%    <- 2:1 拆股
QLD   2021-05-25   126.74 ->   63.20   -50.1%    <- 2:1 拆股
QLD   2025-11-20   135.12 ->   64.38   -52.4%    <- 2:1 拆股（落在 OOS 窗口内）
QQQ                                     0 处      <- 期间未拆股
BIL                                     0 处
```

同一时期的 SIP `adjustment=all` 对照组：

```
TQQQ  2020-03-16     6.77 ->    4.44   -34.5%    <- COVID 熔断日，真实（QQQ -12.2% × 3x）
TQQQ  2025-04-09    19.27 ->   26.06   +35.2%    <- 真实
QLD / QQQ / BIL                         0 处
```

**幻影拆股：IEX 6 处，SIP 0 处。SIP 保留的 2 处都是真实市场事件。**

任何在 2022-01-13 或 2025-11-20 持有 TQQQ/QLD 的策略，
在旧数据上都会记录一次没发生过的腰斩。

---

## 4. 缺陷二：现金腿收益被记成零

```
BIL 2024-01-01 .. 2026-08-04 年化收益
    IEX raw     :  0.01%      （91.41 -> 91.42）
    SIP adj=all :  4.42%      （81.74 -> 91.42）
```

两者终点相同，SIP 把起点回调以反映按月分配。BIL 是 1-3 个月国债 ETF，
2024-2026 恰好是高利率时期，**4.4%/年的无风险收益在旧数据里完全消失了**。

对照 QQQ（股息率低）：IEX 25.44% vs SIP 26.10%——差异小，说明这不是数据损坏，
就是分红调整的有无。

---

## 5. manifest 里的直接证据

VOL02 实际读的四个文件，manifest 里**没有 `adjustment` 字段**，
即使用 Alpaca 默认值 `raw`：

```
qqq_daily_iex.csv   adjustment=(缺失 -> raw)   records=1513
tqqq_daily_iex.csv  adjustment=(缺失 -> raw)   records=1513
qld_daily_iex.csv   adjustment=(缺失 -> raw)   records=1513
bil_daily_iex.csv   adjustment=(缺失 -> raw)   records=1499
```

仓库里存在 47 个 `*_daily_alpaca_iex_all.json`（带 `"adjustment": "all"`），
说明**这个问题曾被部分意识到**，但那些文件只有 123-125 条记录（约半年），
从未回填到回测真正消费的长历史上。

## 6. 影响范围

**受影响**：任何读 `data/cache/*_iex.csv` 且持有杠杆 ETF 或现金腿的回测。
仓库里以 TQQQ 为核心的策略族（`nasdaq_tqqq_fixed_etf_router_*`、
`nasdaq_tqqq_post_drawdown_reentry_router_*` 等）全部落在这个范围内。

**不受影响**：只用 QQQ/SPY 这类未拆股、低股息标的且不持现金的回测，误差在 1-2% 量级。

**与门槛问题的关系**：历史上"32 个候选 0 个通过"的记录，
现在知道有**两个独立的、都已修复的缺陷**——
一个是数学上不可能通过的 DSR 门槛（N=8195），一个是本文档的数据缺陷。
两者叠加，而不是其中之一。

---

## 7. 这个发现**不**能推出什么

必须说清楚边界，避免过度解读：

1. **不能推出"策略其实是赚钱的"。** VOL02 在干净数据上依然**未通过 8 个门槛中的 2 个**
   （夏普和 DSR）。是从"挂 6 个"变成"挂 2 个"，不是通过。
2. **不能推出"过去一律太严"。** 方向是双向的：`sharpe_excess_bil` 用 BIL 当无风险利率，
   旧数据里 BIL≈0 意味着当年在拿 **0% 无风险利率**算超额夏普——**这个指标反而被高估了**。
   两个方向的错误同时存在，现在一起被修正。
3. **不能自动重跑历史候选来"平反"。** 已封存 campaign 的预注册锁绑定了当时的数据与实现；
   要重新评估必须走新的预注册，不能改写封存记录。

## 8. 已采取的行动

- 全部数据切换到 SIP 合并盘（consolidated tape） + `adjustment=all`（`scripts/fetch_sip_universe.py`）。
- IEX 资产在删除前已完整归档到 Drive 并逐文件 md5 校验：
  `datasets/legacy-iex-cache`（149 CSV）、`datasets/legacy-iex-cache-manifests`（151 JSON）、
  `datasets/legacy-iex-research`（1962 文件）。本文档的每个数字都可以从归档重现。
- 新加载器 `open_composer/adapters/data/sip_parquet.py` 在 `frame.attrs` 上固定标注
  `data_source_adjustment="all"`，使调整口径成为 provenance 的一部分而不是隐含假设。

## 9. 对后续工作的约束

**P2 表达式树/遗传编程必须注意**：`adjustment=all` 是后向复权，
历史价格**水平**不等于当时真实成交价（BIL 的 81.74 就是例子）。
比率型特征（趋势缺口、已实现波动率、收益率）不受影响，
但**任何依赖绝对价格水平的算子**（"价格 > $100"、整数关口）在复权序列上是失真的。
GP 算子集合应当排除绝对价格水平比较，只允许比率与排序类算子。
