## 为什么改

1. **研究单位错了。** 过去三周登记了 263 个方向，单独测下来只过了 3 个。
   - 主动管理基本定律：IR ≈ IC × √独立下注数 × 传导系数。
   - 单个股票信号的 IC 只有 0.02–0.05，只有多股票、多信号、风险控制和低成本交易一起上，才能合成可用的夏普。
   - 单独的只做多 top-N 和 ETF 轮动，独立下注数太小，又不控风险，真实但微弱的信号全被判死。
2. **现实量级。**
   - 系统化多空股票基金的净夏普：中位 0.51、90 分位 1.18。
   - 学术上最好的可实施 ML 组合：大盘股净 1.38（JKMP，只扣冲击成本）。
   - 我们的目标是净夏普 0.5–1.0。K2 实际卡在压力期：07:07 主审轮做了合成标定，压力期要约 0.75–0.85，对标窗只要约 0.13–0.26。我原先心算的 0.69 / 0.41 是错的（07:49 更正，见设计第 0 节）。
3. **Stage 0 诊断**（看过的数据，只用于设计）：
   - 流动池里现有信号弱，并且随市场状态翻转符号。8 本书合并后，对标窗 0.58、压力期 −0.23。
   - 次流动池很强，但收益来自做空稀释型小微盘，借券没建模。
   - 用 252 日 beta 做对冲失效，实现 beta 仍有 0.5–0.9。

   所以必须先有风险模型、成本模型和借券约束，再谈信号。

   - 2 倍成本重放同一条权重路径，不重新优化。

   主审同时标定了 K2 的实际门槛（合成书，5% 波动，与 S3 零相关）：压力期要组合净夏普约 0.75（冻结口径）/ 0.85（现金对齐），对标窗只要约 0.13 / 0.26。设计第 0 节估的 0.41 / 0.69 两窗反了：压力期 S3 自身只有 0.645，按波动率倒数加权时组合风险大半落在书上。所以 K2 卡在压力期，需要的净夏普接近职业基金 75 分位；预注册里的先验相应下调（K2 约 10%，research_pass 约 8%）。

   M2、M3 的超参数已固定（T-17 的 GBDT 设置；随机特征 P = 4,000、λ 网格），看到 2a 结果后不能改。S1、D5 和 D3.1 完成后，主审写修正案 A1（只绑定模块哈希），再写 T-08 的简报。结果按冻结门槛判。
4. 有变体通过：
   - v1 + A1 的 watch_recent：开 D6 前向影子。
   - RF1 研究通过或观察档：直接向机主提交模拟盘提议。机主 10-01 同意多开模拟账户，前向两周只验证执行。提议内容：预算、做空授权、整股处理、RF1 第 7 节的失效信号和退出规则。
   - 两条路线都需要两样前置：支持做空的下单引擎，以及每日数据刷新。它们在 Stage 2 运行期间并行开发。
5. 都不过：组合 v1 记为否定，基础设施保留。下一步扩信号库（最后一节），不调参数。
