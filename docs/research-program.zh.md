## 两周证据的总规律（2026-09-18 → 09-30）

- **2024–26 能赚钱的来源只有两类**：
  - 动量 + 杠杆（AI/半导体领涨，S3）；
  - 有持续资金流机制的日历效应（C2：月末反转 + 板块季节性前置）。
- **失败的三种形态**：
  1. 2016–23 有效、2024 起消失：PEAD 变体、MSTR 溢价回归、60/40 再平衡抢跑。
  2. 信号是真的但换手太高，成本吃光：跳空回补、1 分钟路由。
  3. 发表后衰减：国家季节性、多数个股事件信号。
  4. 信号是真的，但数据里的价格拿不到（2026-09-30 加）：
     - 同时段延续：分钟档与日线复权口径不一致，偏差被当成了延续；
     - 一年期隔夜延续：题材股开盘的第一笔成交，高于延迟开出的官方开盘价。
- **推论**：
  - 优先有资金流机制的日历效应。
  - 对"信号真、成本高"的方向，先改执行方式再判死刑。
  - 日内和隔夜方向先用官方竞价价或实测报价核对价格口径，再谈成本。
  - 个股事件/另类数据没有新数据就不再投入。
